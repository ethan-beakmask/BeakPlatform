{{ _('企業管理員的天生權限') }}

{{ _('企業管理員（ORG_ADMIN）天生持有本企業內所有「企業級」和「模組級」權限，無需透過角色指派。') }}

{{ _('這代表：') }}

  • {{ _('企業管理員不需要被加入任何角色就能操作所有企業內功能') }}
