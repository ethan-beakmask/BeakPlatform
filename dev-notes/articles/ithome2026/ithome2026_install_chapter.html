兩台主機練習環境：從零到第一張資安案件

這一章只做一件事：把「平台」和「防禦節點」各裝在一台 Ubuntu 上，在內網跑完 「攻擊事件 → 自動建立資安案件 → 人工簽核 → 封鎖落地到防火牆」整圈。 不需要網域、不需要公網 IP、不需要碰 docker。整章只會下三次指令，其餘全部在瀏覽器裡操作。

  1. 前置作業：你要準備什麼
  2. 環境說明：兩台主機各做什麼
  3. 主機 A：安裝平台（一行指令）
  4. 第一次登入：三個帳號怎麼分
  5. 主機 B：安裝防禦節點（一行指令）
  6. 驗證整條鏈：從測試事件到案件
  7. 選用：用指令建一張案件、收系統信
  8. 卡住時對照表、重來一次

一、前置作業：你要準備什麼

1.1 兩台虛擬機

任何能開兩台 VM 的環境都可以：Proxmox、VMware Workstation、VirtualBox、Hyper-V，或雲端兩台小機器。 規格是練習用（1～3 人同時操作），已經很寬鬆。

帳號一個能 sudo 的一般帳號，安裝過程全程用它

1.2 一把 GitHub Personal Access Token（PAT）

程式碼放在 GitHub 私有 repo，安裝腳本會自己去抓。你需要一把有 repo 權限的 PAT， 兩台安裝都用同一把。建立方式：GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token，勾 repo。

【圖 1-2】GitHub 建立 PAT 的畫面，勾選 repo 權限
PAT 只顯示一次，先貼到記事本。下面的指令裡 <你的PAT> 全部換成它。

1.3 一組密碼

至少 12 碼，含大寫、小寫、數字、特殊符號，例如 Practice2026#Ok。 這一組密碼會同時給系統管理員和示範企業的所有帳號用，練習期間好記比安全重要，事後再改。

三、主機 A：安裝平台（一行指令）

在主機 A 上，把 PAT 與密碼換進去後貼上整段：

curl -sL -H "Authorization: token <你的PAT>" \
  https://raw.githubusercontent.com/ethan-beakmask/BeakPlatform/main/scripts/install.sh \
  | sudo GITHUB_TOKEN=<你的PAT> ADMIN_INITIAL_PASSWORD='<你的密碼>' INSTALL_DEMO=1 bash

腳本會自動裝 PostgreSQL、Redis、nginx、Python 環境，抓程式碼、建資料庫、種出廠資料、設 systemd 服務， 最後因為 INSTALL_DEMO=1 多做兩件事：建立示範企業 DemoSOC，以及發一組給主機 B 用的開通字串。 全程約 3～5 分鐘，多數時間在裝 Python 套件。

五、主機 B：安裝防禦節點（一行指令）

以下全部在主機 B（防禦節點）上執行。回到第三節主機 A 印出的總結，複製「WAF 主機執行指令」那一行，貼到主機 B 的終端機，再補上 PAT、被保護網站與你的工作機 IP：

curl -fsSL -H "Authorization: token <你的PAT>" \
  https://raw.githubusercontent.com/ethan-beakmask/BeakPlatform/main/ITHome2026-WAF/install.sh -o install.sh
sudo GITHUB_TOKEN=<你的PAT> bash install.sh \
  --pair 'ODN1....' \
  --backend http://192.168.0.111:8000 \
  --admin-ips <你的工作機IP> \
  --yes
參數說明
--pair第三節的開通字串，整行貼，前後用單引號包住
--backend要被 WAF 保護的網站。練習時直接填主機 A 自己，之後從 WAF 打進去的流量都會被檢查
--admin-ips允許進 Grafana、EveBox、Portainer 的來源 IP，逗號分隔。不給也能裝，預設放行主機 A 與你 ssh 進來的那台
--yes非互動，缺參數直接報錯而不是停下來問

腳本會裝 docker 與 nftables、抓程式、產生 Suricata / ClickHouse / 防火牆設定、下載 Suricata 規則（約 40 MB）、 啟動所有容器、跑健康檢查，最後印出各服務網址與密碼。全程約 3～6 分鐘，多數時間在抓映像檔。你不需要下任何 docker 指令。

六、驗證整條鏈：從測試事件到案件

在主機 B 上：

sudo bash /opt/ithome2026-waf/install.sh --verify        # 每一項都要綠
sudo bash /opt/ithome2026-waf/install.sh --test-event    # 送一筆假攻擊事件進平台

--verify 會列出容器狀態、WAF 的 SQL injection 探測是否回 403、平台連得到、執行帳號登入成功。 --test-event 送一筆來源 vector、攻擊者 203.0.113.42 的事件，幾秒後 od-bridge 會印 forwarded ... status=200。

【圖 6-1】--verify 全綠的畫面

回主機 A 的平台，用示範企業的資安人員（linda.hu）登入示範企業， 到「開放防禦 → 資安案件處置中心」，會有一張標題含 TEST- 的案件。

【圖 6-2】案件處置中心出現 TEST- 案件
檢查點 C：案件出現，代表主機 B 的事件已經簽章送進主機 A、通過路由、建成案件。這是整章最重要的一個畫面。

接著打開那張案件，填處置意見後按「封鎖攻擊來源」。幾秒內主機 B 的 od-bridge 會印 decision ... action=block target=ip/203.0.113.42，在主機 B 執行 sudo nft list set inet secstack blocklist 會看到 203.0.113.42 timeout 1h； 平台的「開放防禦 → 防禦決策」該筆狀態為 applied。

七、選用：用指令建一張案件、收系統信

7.1 用指令建案件（示範外部系統對接）

除了防禦節點自動送事件，任何外部系統也能用 API Key 直接建案件。這一段示範最小可行的做法。

  1. 用示範企業管理員登入，「系統安全 → API Key 管理」新增一把，授權範圍勾「資安」分類。secret 只顯示一次，按 [複製] 存起來。
  2. 在主機 A 上（任何有 Python 3 的機器都行）：
export BP_BASE_URL='http://192.168.0.111:8000/beakplatform'
export BP_KEY_ID='ak_xxxxxxxx'
export BP_SECRET='<剛複製的 secret>'
python3 /opt/BeakPlatform/scripts/bp_trigger.py --list
python3 /opt/BeakPlatform/scripts/bp_trigger.py \
  --form-code SEC_INCIDENT_RESPONSE --subject 'TEST-手動建單' \
  --field finding_title='TEST-手動建單' --field source_system=manual \
  --field severity_id=3 --field actor_ip=203.0.113.42 --field target_host=demo.internal

回 HTTP 201 就成功，案件處置中心會多一張。--list 會列出這把 key 能發動的表單與每張表單接受的欄位名， 填錯欄位平台會回 400 並把合法欄位名列給你。

【圖 7-1】API Key 建立畫面與 bp_trigger.py 回 201

7.2 收系統信（忘記密碼、新帳號通知）

練習流程本身不需要寄信。真的要收信時，用系統管理員到「主機設定 → 發信服務」建一組 SMTP（以 Gmail 應用程式密碼為例）、設為預設、主要發信服務選 SMTP，按「測試」寄一封確認。

八、卡住時對照表

症狀原因與處置
主機 A 的 curl 回 404PAT 沒帶或 header 寫錯。-H "Authorization: token <PAT>" 那行不能省
開平台網址是 404少了 :8000 或 /beakplatform
主機 B --verify 說平台連不到主機 A 有開防火牆時要放行主機 B 的 IP 打 8000（Ubuntu 預設沒開 ufw，多數人不會遇到）。症狀是逾時，不是 401
od-bridge 一直 401開通字串貼錯或貼到舊的。回主機 A 跑 sudo bash /opt/BeakPlatform/scripts/install.sh --demo 重發一組，主機 B 改 .env 後 --reconfigure

示範企業帳號登入被要求改密碼用錯帳號。示範企業帳號不會強制改密，會的是 admin@sys-xxxx 與 enterprise@sys-xxxx
從別台機器開 :8080 或管理介面連不上主機 B 的所有埠只對主機 A 與 --admin-ips 開放。把那台的 IP 加進 /opt/ithome2026-waf/.env 的 ADMIN_IPS，再 sudo bash /opt/ithome2026-waf/install.sh --reconfigure
忘記示範密碼或開通字串主機 A：sudo cat /opt/BeakPlatform/demo-credentials.txt
兩台時間差太多事件簽章容忍 5 分鐘。兩台都 timedatectl 確認 NTP 有同步

重來一次

# 主機 A（會刪資料庫與目錄，不備份）

# 主機 B

本章結束時你會有的東西

  • 一台平台：系統管理員、示範企業 DemoSOC（管理員、資安人員、資安主管、部門與流程都現成）
  • 一台防禦節點：WAF 擋攻擊、Suricata 看流量、事件自動送進平台建案、核可的封鎖自動落地
