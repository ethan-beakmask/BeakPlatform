BEAKPLATFORM SECURITY ARCHITECTURE

Request Lifecycle - Defense in Depth

INTERNET
Nginx (Reverse Proxy) L1 - Network Edge
Security Headers
注入 X-Frame-Options 等標頭防常見攻擊
Body Size Limit
請求體上限 20MB 防大檔案 DoS
Timeout Control
連線/讀寫逾時 30-60s 防慢速攻擊
Bind localhost
Gunicorn 僅綁 127.0.0.1 不直接對外
Gunicorn (WSGI Server) L2 - Application Server
Request Limits
URL 4KB / Header 100 個 / 單 Header 8KB
Worker Lifecycle
每 1000 請求重啟 Worker 防記憶體洩漏
Request Timeout
30 秒逾時自動終止慢請求
Preload App
啟動時載入應用程式共享記憶體
Flask Middleware L3 - Request Pipeline
before_request (進入)
Auth Interceptor
全域 Deny by Default 認證攔截
Rate Limiter
分層速率限制防暴力破解
Tenant Context
注入 org_secure_code 建立租戶隔離
Page Role Guard
雙鑰匙 (user_type + 角色) 頁面管控
after_request (離開)
Security Headers
動態注入 CSP / HSTS / Permissions-Policy
Audit Logger
三級制操作稽核寫入資料庫
Access Logger
HTTP 存取記錄含真實 IP 與國家
CSRF Validation
Flask-WTF Token 驗證防跨站偽造
Route Decorators L4 - Endpoint Protection
@login_required
強制登入 + 帳號啟用狀態驗證
@admin_required
企業管理員或系統管理員權限
@permission_required
資源級 RBAC + ABAC 條件檢查
@module_access_required
模組合約有效性 + ACL 存取清單
ResourceGateway L5 - Data Access Control
Tenant Filter
自動注入 org_secure_code 查詢條件
secure_code Validation
正則驗證識別碼格式防注入攻擊
Protected Fields
禁止修改 id / secure_code 等核心欄位
Soft Delete Filter
自動過濾已刪除與停用的記錄
SQLAlchemy ORM L6 - Query Layer
Parameterized Queries
所有查詢參數化防 SQL 注入
Connection Pool
pre_ping + 5 分鐘回收確保連線健康
TenantBaseModel
租戶表自動繼承 org_secure_code 欄位
PostgreSQL L7 - Database
Row Level Security
資料庫層租戶隔離最後防線
pgcrypto
資料庫層級加密與雜湊函式
Dedicated DB User
應用程式專用帳號限定存取範圍
Cross-Cutting Concerns 橫切面安全措施
Session (Redis)
HttpOnly / Secure / SameSite / 4hr 過期
Password Security
bcrypt 雜湊 + 策略引擎 + 帳號鎖定
Secret Management
.env chmod 600 / 缺 KEY 中斷啟動
PII Masking
Email / IP 遮罩防個資洩露於日誌
Semgrep SAST
9 條規則自動掃描硬編碼與注入風險
Service Account
nologin 專用帳號最小權限執行服務
