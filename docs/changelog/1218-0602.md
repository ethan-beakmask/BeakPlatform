## 安全漏洞修復

### 1. 登入表單密碼洩漏 (嚴重)
**問題**: 登入表單缺少 `method="POST"`，當 JavaScript 失敗時，瀏覽器用 GET 方式提交，密碼出現在 URL。

**原因**:
- 表單只依賴 Alpine.js 的 `@submit.prevent`
- 模板繼承結構錯誤導致 JavaScript 未載入

**解決**:
```html
<!-- 必須加上 method="POST" 作為安全 fallback -->
<form method="POST" action="{{ url_for('auth.login') }}" @submit.prevent="submit">
```

**教訓**: 永遠不要只依賴 JavaScript 處理表單，HTML 層面必須有安全 fallback。

### 2. CSRF Session Token Missing
**問題**: 登入時出現 "The CSRF session token is missing"

**原因**: Flask-WTF CSRF 驗證需要 session，但登入端點不應該需要 CSRF（沒有已登入 session 可被攻擊）

**解決**:
```python
@auth_bp.route('/login', methods=['GET', 'POST'])
@csrf.exempt  # 登入不需要 CSRF
def login():
```

### 3. 安全登出實作
**問題**: 登出需要完全清除 session，防止記憶體殘留

**解決**:
```python
def logout():
    logout_user()           # Flask-Login 登出
    session.clear()         # 完全清除 session
    session.modified = True # 強制重新生成
```

## 系統問題修復

### 4. Blueprint 名稱衝突
**問題**: API 和 Web 都有 `users`、`organizations` blueprint，Flask 報錯。

**解決**: API blueprints 改名為 `api_users`、`api_organizations`
```python
# backend/app/api/users.py
users_bp = Blueprint('api_users', __name__)

# backend/app/api/organizations.py
organizations_bp = Blueprint('api_organizations', __name__)
```

### 5. 資料庫連線問題
**問題**: 連線 port 5433 被拒絕

**原因**: `.env` 設定錯誤，PostgreSQL 實際在 5432

**解決**: 修正 `.env`
```
DATABASE_URL=postgresql://beakmask:postgres123@localhost:5432/beakmask_dev
```

### 6. 資料庫權限問題
**問題**: `permission denied for table users`

**原因**: RLS 政策和權限設定問題

**解決**:
```sql
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO beakmask;
GRANT ALL PRIVILEGES ON ALL SEQUENCES IN SCHEMA public TO beakmask;
ALTER TABLE users DISABLE ROW LEVEL SECURITY;  -- 開發階段暫時停用
```

### 7. 密碼驗證失敗
**問題**: 正確密碼無法登入

**原因**: 資料庫中的 password_hash 與實際密碼不匹配

**解決**: 重新生成 bcrypt hash
```python
import bcrypt
hashed = bcrypt.hashpw(b'admin123', bcrypt.gensalt(rounds=12))
```
```sql
UPDATE users SET password_hash = '$2b$12$...' WHERE email = 'admin@beakmask.local';
```

## 前端問題修復

### 8. Tailwind CSS @apply 語法失效
**問題**: CSS 使用 `@apply` 語法，但 Tailwind CDN 版不支援

**原因**: CDN 版 Tailwind 是 JIT 編譯，不處理 `@apply`

**解決**: 改用純 CSS，不使用 `@apply`

### 9. SVG 佔據整個畫面
**問題**: SVG 圖標沒有尺寸限制，佔滿整個視窗

**原因**:
- Tailwind classes (w-6 h-6) 未生效
- SVG 預設會擴展到容器大小

**解決**: 移除所有裝飾性 SVG，改用純文字符號
```html
<!-- 之前 -->
<svg class="w-6 h-6">...</svg>

<!-- 之後 -->
←
```

### 10. Layout 結構問題
**問題**: 模板繼承導致 JavaScript 未載入

**原因**: login.html 用 `{% block body %}` 替換整個 body，導致 `{% block scripts %}` 被忽略

**解決**:
- login.html 改為獨立完整頁面，不繼承 base.html
- base.html 使用純 CSS inline styles，不依賴 Tailwind
