# Changelog 2025-12-19 03:00

## 變更摘要

實作企業客戶管理系統，包含企業合約管理、組織架構（部門/群組）、角色/職務管理，以及新的登入流程。

## 完成項目

### Phase 1: 企業與合約管理

1. **Organization 模型改造** (`backend/app/models/organization.py`)
   - 新增 `domain_name`: 登入網域識別（如 acme.com.tw）
   - 新增 `customer_type`: 客戶類型（TRIAL/FORMAL/BLACKLIST）
   - 新增 `user_limit`: 帳號數量上限
   - 新增聯絡資訊欄位
   - 新增 `is_contract_valid()`: 合約有效期驗證
   - 新增 `get_contract_valid_range()`: 取得所有合約的有效期間
   - 特殊企業 `system.local` 永久有效，不受合約限制

2. **Contract 模型建立** (`backend/app/models/contract.py`)
   - Master-Detail 結構（企業:合約 = 1:N）
   - 合約編號格式: CTR-YYYYMMDD-XXXX
   - 合約期間: start_date, end_date
   - 狀態: ACTIVE/DISABLED
   - 模組配置預留欄位 (modules_config)

3. **登入流程改造** (`backend/app/api/auth.py`)
   - 共用登入頁: `/auth/login` (格式: username@domain_name)
   - 企業專屬登入頁: `/auth/org/<domain_name>/login` (只需 username)
   - 登入驗證整合合約有效期檢查
   - 更新登入頁面模板支援兩種登入模式

### Phase 2: 組織架構管理

4. **OrganizationalUnit 模型** (`backend/app/models/organizational_unit.py`)
   - 部門與群組使用同一張表，透過 `unit_type` 區分
   - 樹狀結構: parent_secure_code, full_path, level
   - 自動更新路徑方法

5. **User-Unit 關聯表** (`backend/app/models/associations.py`)
   - `UserUnitAssignment`: 多對多關係
   - 支援主要單位標記 (is_primary)

### Phase 3: 角色/職務管理

6. **Role 模型** (`backend/app/models/role.py`)
   - 職務與角色使用同一張表，透過 `role_type` 區分
   - 適用範圍: GLOBAL/DEPARTMENT/GROUP
   - 樹狀結構支援
   - 管理者角色標記 (is_manager)
   - 系統預設角色標記 (is_system_role)

7. **User-Role 關聯表** (`backend/app/models/associations.py`)
   - `UserRoleAssignment`: 多對多關係
   - 支援在特定單位擔任角色
   - 支援有效期限 (valid_from, valid_until)

### Phase 4: User 模型改造

8. **User 模型更新** (`backend/app/models/user.py`)
   - 新增 `username`: 組織內唯一，用於登入
   - 新增 `user_type`: SYSTEM_ADMIN/ORG_ADMIN/EMPLOYEE/EXTERNAL
   - 新增 `can_login()`: 登入權限檢查（整合合約驗證）
   - 移除 is_org_admin, is_system_admin 欄位（改用 user_type）
   - 保留 property 向後相容

### 服務層

9. **OrganizationService** (`backend/app/services/organization_service.py`)
   - `create_organization()`: 建立企業並自動建立預設管理員
   - `create_contract()`: 建立合約
   - `create_organization_with_contract()`: 同時建立企業和合約
   - `init_system_organization()`: 初始化系統企業
   - 自動建立預設角色（企業管理員、部門主管、群組召集人、一般員工）

### API 層

10. **Contract API** (`backend/app/api/contracts.py`)
    - CRUD 操作（系統管理員）
    - 企業管理員可檢視自己的合約

11. **OrganizationalUnit API** (`backend/app/api/organizational_units.py`)
    - 部門/群組 CRUD
    - 樹狀結構查詢
    - 自動建立成員角色

12. **Role API** (`backend/app/api/roles.py`)
    - 角色/職務 CRUD
    - 樹狀結構查詢
    - 系統角色保護

13. **Organization API 更新** (`backend/app/api/organizations.py`)
    - 整合 OrganizationService
    - 新增統計資訊端點

## 資料結構概覽

```
Organization (企業)
├── domain_name (登入識別)
├── customer_type (客戶類型)
├── user_limit (帳號上限)
│
├── Contracts (合約) 1:N
│   ├── start_date, end_date
│   └── status
│
├── OrganizationalUnits (組織單位) 1:N
│   ├── DEPARTMENT (部門) - 樹狀
│   └── GROUP (群組) - 樹狀
│
├── Roles (角色/職務) 1:N
│   ├── POSITION (職務)
│   └── ROLE (角色)
│
└── Users (帳號) 1:N
    ├── username (組織內唯一)
    └── user_type (帳號類型)

關聯表:
- user_unit_assignments (用戶-組織單位)
- user_role_assignments (用戶-角色，可指定在哪個單位)
```
