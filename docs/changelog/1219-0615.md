# 變更記錄 - 2025-12-19 06:15

## 變更摘要

完成動態選單系統的除錯與修復，改為伺服器端渲染以解決 Alpine.js 相容問題。

---

## 本次修復項目

### 1. Alpine.js 問題修復
- 將 Alpine.js 版本從 `@3.x.x` 固定為 `@3.14.3`
- 添加 `[x-cloak]` CSS 規則防止未初始化元素閃爍

### 2. 模組建立 (POST fallback)
- `/modules/create` 路由新增 POST 方法支援
- 表單欄位添加 `name` 屬性
- 友善化重複代碼錯誤訊息

### 3. 模組詳情頁 (伺服器端渲染)
- `view_module()` 路由改為伺服器端取得資料
- `view.html` 改為純 Jinja2 渲染，移除 Alpine.js 依賴

### 4. 動態選單 (伺服器端渲染)
- 新增 `register_context_processors()` 注入 `nav_menu`
- `base.html` 選單改為純 CSS hover 下拉選單
- 移除對 `components/menu.html` Alpine.js 元件的依賴
