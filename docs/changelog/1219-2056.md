整合並完善 **Phase 1: 動態 Menu + 網頁權限管理系統** 與 **組織架構管理系統**，包含角色管理、組織單位管理、合約管理的 Web 頁面建立與修復。

## 完成項目

### 1. 預設角色資料建立

為現有企業 (beakmask.local) 建立 4 個預設角色：
- 企業管理員 (ORG_ADMIN) - 全企業範圍
- 部門主管 (DEPT_MANAGER) - 部門範圍
- 群組召集人 (GROUP_CONVENER) - 群組範圍
- 一般員工 (EMPLOYEE) - 全企業範圍

### 2. 角色管理頁面

- 更新 `web/roles.py` 使用正確的 ResourceGateway API
- 建立 `templates/pages/roles/list.html` - 角色列表頁面
- 建立 `templates/pages/roles/view.html` - 角色詳情頁面
- 系統預設角色標記為不可編輯

### 3. 組織單位管理頁面

- 建立 `web/units.py` - Web 路由
- 建立 `templates/pages/units/list.html` - 單位列表（支援部門/群組篩選）
- 建立 `templates/pages/units/view.html` - 單位詳情
- 建立 `templates/pages/units/create.html` - 建立單位
- 建立 `templates/pages/units/edit.html` - 編輯單位
- 註冊 Blueprint 到 `/units/`

### 4. 合約管理頁面

- 建立 `web/contracts.py` - Web 路由（系統管理員專用）
- 建立 `templates/pages/contracts/list.html` - 合約列表（含篩選）
- 建立 `templates/pages/contracts/view.html` - 合約詳情
- 建立 `templates/pages/contracts/create.html` - 建立合約
- 建立 `templates/pages/contracts/edit.html` - 編輯合約
- 註冊 Blueprint 到 `/contracts/`

### 5. 選單項目新增

新增 2 個選單項目：
- 組織單位 (level=1, 企業管理員可見)
- 合約管理 (level=0, 系統管理員可見)

### 6. ResourceGateway API 修正

修正 web 路由使用正確的 ResourceGateway 方法：
- `ResourceGateway.list()` 取代錯誤的 `query_all()`
- `ResourceGateway.get()` 取代錯誤的 `get_by_secure_code()`
