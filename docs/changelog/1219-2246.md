# Changelog 2025-12-19 22:46

## 變更摘要
將整個網站轉換為純 HTML 風格，移除 Tailwind CSS 和 Alpine.js 相依性

## 完成項目

### 1. 純 HTML 風格轉換
**背景**: 上一版本使用 Tailwind CSS 和 Alpine.js 導致嚴重的 CSS/JS 衝突問題

**轉換的頁面**:
- `layouts/base.html` - 基礎版面，改用純 CSS 內嵌樣式
- `auth/login.html` - 登入頁面
- `pages/dashboard.html` - 儀表板
- `pages/users/` - 用戶管理 (list, view, create, edit)
- `pages/organizations/` - 企業管理 (list, view, create, edit)
- `pages/profile/` - 個人資料 (view, edit, password)
- `pages/roles/` - 角色管理 (list, create)
- `pages/units/` - 組織單位管理 (list, view, create, edit)
- `pages/contracts/` - 合約管理 (list, view, create, edit)
- `pages/menu/` - 選單管理 (list, create, edit)
- `pages/modules/` - 模組管理 (list, view, create, edit)
- `errors/` - 錯誤頁面 (401, 403, 404, 500)

### 2. Web 路由 POST 處理
為所有管理頁面加入 POST 表單處理，不再依賴 JavaScript API 呼叫：
- `web/users.py` - 用戶 CRUD
- `web/organizations.py` - 企業 CRUD
- `web/profile.py` - 個人資料編輯、密碼變更
- `web/menu.py` - 選單項目 CRUD
- `web/modules.py` - 模組 CRUD

### 3. 風格統一
- 表格使用 `<table border="1" cellpadding="8" cellspacing="0">`
- 表單使用 `<table border="0" cellpadding="4" cellspacing="0">`
- 連結使用 `[文字]` 格式 (如 `[查看]`, `[編輯]`)
- 刪除操作用 `confirm()` 確認
- Flash messages 用 `<p><strong>{{ message }}</strong></p>`

## 技術決策
1. **移除外部相依**: 不再使用 Tailwind CSS CDN 和 Alpine.js
2. **內嵌 CSS**: base.html 使用 `<style>` 標籤定義基本樣式
3. **傳統表單**: 所有表單使用 POST 提交到同頁面處理
4. **伺服器端渲染**: 選單和所有資料都在伺服器端用 Jinja2 渲染

- 移除外部相依: Tailwind CSS, Alpine.js
