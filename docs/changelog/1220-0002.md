# 變更記錄 2024-12-20 00:02

## 變更摘要

新增公開專區 (Portal) 和 DB Viewer 開發工具，以及服務重啟腳本。

## 完成項目

### 1. 公開專區 /portal
- 建立 `backend/app/web/portal.py` - Portal Blueprint
- 建立 `backend/app/templates/layouts/portal_base.html` - Portal 專用 Layout
- 建立 `backend/app/templates/pages/portal/index.html` - Portal 首頁
- 更新 `backend/app/security/auth_interceptor.py` - 加入 `/portal/` 到公開路由前綴
- 更新 `backend/app/web/__init__.py` - 註冊 Portal Blueprint

特點：
- 深色主題 UI，有別於主系統
- 不需登入即可存取
- 適合放置官網、公佈欄、開發工具

### 2. DB Viewer 資料表檢視器
- 建立 `backend/app/templates/pages/portal/db_viewer.html`
- 功能：
  - 動態取得所有資料表
  - 顯示各表總筆數（由大到小排序）
  - 顯示每個表最新 10 筆資料（依 created_at 或 id 逆排）
  - 敏感欄位（password, secret, token）模糊顯示
  - 一鍵重新整理

訪問路徑: `/portal/db-viewer`

### 3. 服務重啟腳本
- 建立 `restart_flask.sh` - 從 FormFlow 複製並適配
- 功能：
  - 智能檢測虛擬環境
  - 停止現有 Flask 進程
  - 自動載入 .env 環境變數
  - 啟動服務並驗證
  - 顯示服務日誌
