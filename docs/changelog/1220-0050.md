# 變更記錄 2024-12-20 00:50

## 變更摘要

重構選單權限系統，從「required_level 繼承模式」改為「MenuPermission 交叉表平行模式」。

## 問題背景

原設計使用 `required_level` 數字（0=系統管理員, 1=企業管理員, 2=一般用戶），假設「系統管理員 > 企業管理員 > 一般用戶」的繼承關係。這導致系統管理員能看到所有企業選單，違反 ISO27001/27701 的隱私要求。

## 新設計

採用 **MenuPermission 交叉表**，各用戶類型是「平行」關係：

| 選單類型 | SYSTEM_ADMIN | ORG_ADMIN | EMPLOYEE | EXTERNAL |
|---------|--------------|-----------|----------|----------|
| 系統專屬功能 | ✓ | - | - | - |
| 企業管理功能 | - | ✓ | - | - |
| 員工功能 | - | ✓ | ✓ | - |
| 公開功能 | ✓ | ✓ | ✓ | ✓ |

系統管理員只能看到 SYSTEM.local 企業的選單，不會自動看到其他企業的選單。
