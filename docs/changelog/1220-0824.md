## 新增模型

### 1. JobLevel (職等)
**用途：** 定義組織內的層級結構，決定簽核權限金額

| 等級 | 名稱 | 簽核上限 | 管理幅度 |
|-----|------|---------|---------|
| L9 | 總經理級 | 無上限 | 全公司 |
| L8 | 副總經理級 | 5,000萬 | 多處室 |
| L7 | 處長級 | 1,000萬 | 單一處室 |
| L6 | 副處長級 | 500萬 | 協助處室 |
| L5 | 經理級 | 100萬 | 單一部門 |
| L4 | 副理級 | 50萬 | 協助部門 |
| L3 | 主任級 | 10萬 | 小組/專案 |
| L2 | 高級職員級 | 5萬 | - |
| L1 | 職員級 | 1萬 | - |

### 2. JobFamily (職系)
**用途：** 定義職涯發展軌道（雙軌制）

- **管理職 (MANAGER):** 帶人主管軌道
- **專業職 (PROFESSIONAL):** 不帶人的專業軌道
  - 業務職 (SALES)
  - 客服職 (CS)
  - 行政職 (ADMIN)
  - 工程技術職 (TECH)

### 3. JobTitle (職稱)
**用途：** 職等 + 職系 的具體組合

範例：
- 經理 (Manager) = L5 + 管理職
- 專案經理 (Project Manager) = L5 + 工程技術職
- 業務代表 (Sales Representative) = L1 + 業務職

### 4. EmployeePosition (員工職位)
**用途：** 紀錄員工的職位指派，**最重要的是直屬主管關係**

關鍵欄位：
- `direct_manager_secure_code` - 直屬主管（表單簽核必備）
- `dotted_line_manager_secure_code` - 虛線主管（Matrix 組織）
- `position_type` - PRIMARY/CONCURRENT/ACTING/TEMPORARY
- `is_unit_head` - 是否為部門主管

### 5. Delegation (代理授權)
**用途：** 職務代理機制，避免主管不在時流程卡住

功能：
- 全權代理 / 限定金額代理 / 特定流程代理
- 有效期限控制
- 撤銷機制

## 資料結構關係圖

```
User (員工)
  │
  ├── EmployeePosition (職位指派)
  │     ├── JobTitle (職稱)
  │     │     ├── JobLevel (職等) → 簽核權限金額
  │     │     └── JobFamily (職系) → 職涯發展軌道
  │     ├── OrganizationalUnit (部門)
  │     └── direct_manager → User (直屬主管)
  │
  └── Delegation (代理授權)
        ├── delegator → User (授權人)
        └── delegate → User (被授權人)
```

## 表單簽核流程支援

現在可以實現：

1. **找直屬主管：** `employee_position.direct_manager_secure_code`
2. **主管鏈：** `EmployeePosition.get_manager_chain()`
3. **簽核金額：** `job_level.approval_limit`
4. **代理機制：** `Delegation` 查詢
