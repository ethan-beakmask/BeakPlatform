## 設計變更

### 職等序號改為等距跳號

**原設計 (連續號)：**
```
L1 → L2 → L3 → L4 → L5 → L6 → L7 → L8 → L9
```
問題：若要在 L1 和 L2 之間插入新職等，需要重新編號所有職等。

**新設計 (等距跳號)：**
```
L000 → L100 → L200 → L300 → L400 → L500 → L600 → L700 → L800 → L900
```
優點：可在任意兩職等之間插入新職等，不影響既有流程設計。

### 插入新職等範例

```
原有：L100 (職員) 和 L200 (高級職員)
插入：L150 (新職等)

再次細分：
L150 和 L200 之間 → L175
L175 和 L200 之間 → L187
```

### 新增 L000 外部人員

專門處理非正式員工的職等：
- CONTRACTOR (約聘人員)
- INTERN (實習生)
- VENDOR (廠商代表)

簽核權限金額上限：0 (無簽核權限)

## 新增輔助方法

`JobLevel` Model 新增：

```python
@staticmethod
def calculate_insert_order(lower_order: int, upper_order: int) -> int:
    """計算插入位置：(100 + 200) // 2 = 150"""

@classmethod
def suggest_new_level_code(cls, lower_order, upper_order) -> str:
    """建議新職等代碼：L150"""
```
