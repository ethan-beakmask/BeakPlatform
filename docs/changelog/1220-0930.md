### 新增檔案
- `backend/app/web/job_levels.py` - 網頁路由

### 功能
- 列表頁：顯示所有職等，依序號由高到低排序
- 詳情頁：顯示職等完整資訊

### URL
- `/job-levels/` - 列表
- `/job-levels/<secure_code>` - 詳情
- `/job-levels/create` - 新增
- `/job-levels/<secure_code>/edit` - 編輯
