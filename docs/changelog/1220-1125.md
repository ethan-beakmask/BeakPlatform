# Changelog 2024-12-20 11:25

## 變更摘要
**安全性修正**: 修正 secure_code 格式，從可猜測的格式改為使用 `token_urlsafe(16)` 生成的隨機 token。

## 問題說明

### 發現的安全問題
之前的 seed 資料使用可猜測的 secure_code 格式：
```
org_default_00000000001  (可猜測)
jl_l900_default_0001     (可猜測)
jf_mgr_default_00001     (可猜測)
```

### 正確的格式
應使用 `secrets.token_urlsafe(16)` 生成 22 字元隨機 token：
```
3XChEVpp30L-UdbK_o_EPZ  (不可猜測)
OLP13AdWPBDm24BlGOS34-  (不可猜測)
izgArVrb0IsEImoj46IRP3  (不可猜測)
```

## 修正內容

### 1. 建立 Python Seed 腳本
新增 `scripts/seed_data.py`，使用 Model 建立資料，讓 secure_code 自動生成：

```bash
# 執行方式
cd /opt/BeakMask
source venv/bin/activate
set -a && source .env && set +a
python scripts/seed_data.py
```

### 2. 移除 SQL 中的硬編碼 secure_code
- 修改 `scripts/init_db.sql`，移除 seed data 區塊
- 將 `scripts/migrations/005_seed_job_structure.sql` 重新命名為 `.deprecated`

### 3. 安全性檢查
確認 Model 層的 `generate_secure_code()` 正確使用 `secrets.token_urlsafe()`
