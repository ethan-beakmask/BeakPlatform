## 問題說明

### 發現的安全問題
1. **002_organization_contracts.sql** 使用可猜測前綴：
   - `SYSTEM_ORG_` + MD5 隨機 10 字元
   - `ADMIN_` + MD5 隨機 16 字元

2. **003_menu_permissions.sql** 使用 MD5 截斷：
   - `substr(md5(random()::text), 1, 22)` 生成 secure_code
   - MD5 有碰撞風險，不如 `token_urlsafe(16)` 安全
