# Changelog 變更記錄

## 命名規則

檔案格式: `MMDD-HHMM.md`

- **MM**: 月份 (01-12)
- **DD**: 日期 (01-31)
- **HH**: 小時 (00-23)
- **MM**: 分鐘 (00-59)

範例: `1218-0458.md` = 12月18日 04:58

## 內容結構

```markdown
# Changelog: YYYY-MM-DD HH:MM

## 版本資訊
- **日期**: YYYY-MM-DD
- **時間**: HH:MM
- **類型**: [新功能 | 修復 | 重構 | 安全 | 文件]

---

## 變更摘要

### 🎉 新增功能
...

### 🐛 修復
...

### 🔧 重構
...

### 🔒 安全
...

---

## 下一步
...

---

## 備註
...
```

## 記錄時機

1. **每次對話結束時** - 記錄該對話完成的工作
2. **重要里程碑** - 模組完成、功能上線
3. **安全修復** - 必須詳細記錄
