      ## 系統管理員儀表板

      系統管理員登入後的首頁，提供整個 BeakPlatform 部署的健康狀態總覽。

      ### 主要顯示資訊

      - **企業總數**：目前部署上有多少家企業（不含系統企業）
      - **線上用戶數**：所有企業近期活躍的帳號統計
      - **系統資源**：CPU / 記憶體 / 磁碟使用率
      - **近期登入錯誤**：跨企業的登入失敗摘要（詳情請至「登入錯誤監看」）
      - **緊急廣播**：目前掛在系統列、由系統管理員發出的全站訊息

      ### 常見操作

      - 點擊任一統計卡片可跳到對應詳情頁
      - 右上角「快速設定」可進入「主機設定」維護平台層參數

      ### 注意事項

      系統管理員的儀表板**不顯示任何企業的業務資料**（依 ISO27001/27701 隱私要求隔離）。
      如需檢視特定企業的業務指標，請以該企業的管理員帳號登入。

  - audience: ORG_ADMIN

      ## 企業管理員儀表板

      您所屬企業的營運總覽。

      ### 主要顯示資訊

      - **成員統計**：在職人數、本月新增/停用帳號數
      - **未完成簽核**：以您為當前簽核人的待辦表單數量
      - **本企業緊急廣播**：由您或其他企業管理員發出、目前仍生效的訊息
      - **模組使用狀況**：已啟用的業務模組與近期使用次數

      ### 常見操作

      - 點擊「成員統計」卡片進入「企業成員帳號」管理頁
      - 點擊「未完成簽核」進入「表單中心」
      - 右上角「企業設定」可調整本企業的標題、Logo、時區等

  - audience: EMPLOYEE
    body: |
      ## 個人儀表板

      您登入後看到的個人首頁。

      ### 主要顯示資訊

      - **我的待辦**：以您為當前簽核人的表單清單
      - **我送出的表單**：您發起且尚未完成的流程
      - **本企業最新公告**：由企業管理員發布的訊息

      ### 常見操作

      - 點擊待辦項目直接進入該表單進行簽核
      - 右上角頭像可進入「個人設定」修改密碼、時區等
