      ## 企業成員帳號管理

      管理本企業內所有員工帳號，包含建立、停用、重設密碼、指派角色與部門等。

      ### 列表頁

      - **欄位**：員工編號、顯示名稱、Email、所屬部門、角色、狀態、最後登入時間
      - **欄位排序**：表頭顯示向上/向下三角形者皆可排序
      - **篩選**：以「狀態」、「部門」、「角色」快速縮小範圍
      - **搜尋**：依姓名、Email、員工編號搜尋

      ### 新增成員

      點擊 `[新增成員]` 按鈕後填寫：

      | 欄位 | 必填 | 說明 |
      |---|---|---|
      | 員工編號 | 是 | 企業內唯一，用於整合 HR 系統 |
      | Email | 是 | 登入帳號，企業內唯一 |
      | 顯示名稱 | 是 | 出現在系統列、簽核紀錄 |
      | 部門 | 否 | 可在 `部門管理` 預先建立 |
      | 角色 | 是 | 至少指派一個角色，預設 `EMPLOYEE` |
      | 初始密碼 | 是 | 建議勾選「首次登入強制變更」 |

      ### 停用 vs 刪除

      - **停用**（`is_active=False`）：保留資料，無法登入，仍出現在簽核歷史
      - **刪除**（軟刪除 `is_deleted=True`）：從所有列表消失，**包含表單簽核可選人**

      重要：刪除帳號**不影響**該帳號過去已簽核的表單記錄。

      ### 注意事項

      - 帳號的 Email 是登入唯一識別，**不可重複**且**不建議變更**
      - 密碼重設僅能由企業管理員執行；員工自行重設請走「忘記密碼」流程

      ## 企業成員帳號（系統管理員視角）

      系統管理員**通常不應**直接管理企業內的員工帳號（依 ISO27001/27701 隱私要求）。
      此頁在 SYSTEM_ADMIN 身份下主要用途為：

      - **緊急介入**：客戶報修「企業管理員忘了自己的密碼且無備援管道」
      - **資料清查**：應企業要求協助找出某個資料的建立者

      ### 跨企業檢視

      頁面頂部的「企業」下拉選單可切換到任一企業的成員列表。
      切換後**所有操作會被審計記錄**，包含瀏覽行為。

      ### 限制

      - 無法檢視員工的個人隱私欄位（手機、生日等加密欄位）
      - 重設密碼後系統會強制企業管理員下次登入時收到通知信

      ### 替代方案

      若客戶只是要找企業管理員，請改用「組織管理」頁查詢該企業的 ORG_ADMIN 角色擁有者。
