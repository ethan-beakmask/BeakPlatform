# BeakPlatform 使用手冊

本手冊面向平台的**最終使用者**——企業管理員、資安人員、一般員工。
開發與維運相關的設計文件不在這裡。

!!! note "文件正在建置中"
    目前只有部分主題完成。缺少的章節會陸續補上，
    以每個版本的實際行為為準。

## 怎麼用這份手冊

- 左側是完整目錄，依「前置設定 → 作業流程」的實際順序排列
- 頁面開頭若出現黃色的「開始前必須先完成」方框，代表這件事有前置作業，
  跳過會導致流程中途卡住
- 頁面結尾的藍色方框列出「本頁產出的資料被哪些後續作業使用」
- 右上角放大鏡可全文搜尋，**離線也能用**（搜尋索引隨頁面一起打包）

## 取得離線版

整個 `site/` 目錄可直接複製走，用瀏覽器開啟 `index.html` 即可閱讀，
不需要網路連線，也不需要架設伺服器。
