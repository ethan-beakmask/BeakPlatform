# 用 SMTP 寄送系統信

安裝平台時不需要另外裝 E-MailRelay。系統信可以直接在 UI 建一組系統級 SMTP，設為預設後指定主要發信服務為 SMTP。

## 一、進入發信服務

用系統管理員進入：

```text
http://<平台IP>:<埠>/beakplatform/hostconfig/server-settings
```

左側分類選「發信服務」。頁面內有「指定發信服務」與「SMTP 設定組（系統級）」。

## 二、新增 Gmail SMTP 設定

在「SMTP 設定列表」按「新增設定」，以 Gmail 為例填：

| 欄位 | 建議值 |
|---|---|
| 設定名稱 | `Gmail 主要` |
| 描述 | 選填 |
| 提供者 | `Gmail` |
| SMTP 伺服器 | `smtp.gmail.com` |
| 連接埠 | `587` |
| 使用 STARTTLS | 勾選 |
| 使用 SSL | 不勾 |
| 帳號 | Gmail 帳號 |
| 密碼 | Gmail「應用程式密碼」 |
| 寄件人 Email | 要顯示的寄件人信箱 |
| 寄件人名稱 | 例如 `BeakPlatform` |
| 優先順序 | 可保留 `100` |
| 設為預設 | 勾選 |
| 啟用 | 勾選 |

Gmail 密碼請使用「應用程式密碼」，不要填一般登入密碼。

## 三、指定主要發信服務

回到「指定發信服務」：

1. 選 `SMTP`
2. 不需要勾「同一封信讓兩個服務都發（提高收信成功機率）」
3. 按「儲存發信服務」

SMTP 被指定為發信服務時，系統信會使用勾了「設為預設」的那一組寄出。

## 四、測試寄送

回到「SMTP 設定列表」，對剛建立的設定按「測試」。如果測試失敗，優先檢查：

- `SMTP 伺服器`、`連接埠`、`使用 STARTTLS` 是否符合郵件服務商規定
- `帳號` 是否完整
- `密碼` 是否為應用程式密碼
- 防火牆是否允許主機連到 SMTP 伺服器

## 五、哪些功能會寄信

平台自己的系統信會走這裡指定的服務，包含：

- 忘記密碼
- 新帳號通知或暫時密碼
- 管理員重設密碼通知
- 登入救助警報
