# BeakPlatform 工單模板

提交工單時複製以下模板，填寫必要欄位即可。AI 會根據「目標頁面」查找 manifest，精準定位檔案。

---

## 標準工單

```
目標頁面: /users/
問題類型: bug | 功能調整 | 新增欄位 | UI 修正 | 效能
症狀: （簡述看到的問題或想要的效果）
影響範圍: （list / create / edit / view / 全部）
已知線索: （選填，你觀察到的任何線索）
```

## 範例

### Bug 範例
```
目標頁面: /users/
問題類型: bug
症狀: 編輯頁儲存後 email 欄位沒更新
影響範圍: edit
已知線索: form 裡有 email input，但 POST 後 DB 沒變
```

### 功能調整範例
```
目標頁面: /menu/
問題類型: 功能調整
症狀: 希望拖曳排序後自動儲存，不用按儲存按鈕
影響範圍: list
已知線索: 無
```

### 新增欄位範例
```
目標頁面: /roles/
問題類型: 新增欄位
症狀: 角色需要新增「有效期限」欄位（date 類型）
影響範圍: create / edit / list
已知線索: 無
```

### 跨功能範例
```
目標頁面: /users/ + /admin/account-roles/
問題類型: bug
症狀: 新建帳號後在帳號角色頁看不到該帳號
影響範圍: 跨頁面
已知線索: 可能是 is_active 預設值問題
```

---

## AI 處理流程

1. 讀取 `docs/manifests/README.yaml` 找到對應 manifest
2. 讀取 manifest 取得精確檔案清單
3. 只讀取 manifest 列出的檔案（不做額外探索）
4. 在目標檔案中定位問題並修正
5. 如果 manifest 中的檔案不足以解決問題，向用戶說明需要查看哪些額外檔案及原因
