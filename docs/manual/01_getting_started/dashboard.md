# 儀表板

登入後的首頁，只有兩張卡片：**待簽核**與**我的社群**。它不是營運報表，
沒有圖表也沒有企業層級的統計。

!!! abstract "作業：看有沒有東西等我簽"
    **MENU**：儀表板

    1. 看「待簽核」卡片的數字，紅色代表大於 0
    2. 到「表單中心」處理（儀表板的卡片本身不能點）

## 兩張卡片怎麼算

| 卡片 | 算什麼 | 為什麼可能與你的認知不同 |
|---|---|---|
| 待簽核 | 目前停在你這一關、等你決定的簽核任務數 | 包含別人授權你代理的任務；已經有人（例如同一組的另一位簽核者）處理掉的不算 |
| 我的社群 | 你以成員身分參與的社群數 | 只算社群（跨部門群組），部門不算；停用的社群不算 |

「我的社群」大於 0 時，底下會列出每個社群與你在裡面的位階，召集人以藍字標示。

## 各身分看到的差別

- **企業成員與外部廠商**：兩張卡片就是全部
- **企業管理員**：多一段安全提醒。用原始的 `admin` 帳號登入時提醒你建立正式的管理員帳號；
  用正式帳號登入而原始帳號還啟用著時，提醒你去停用它。停用後提醒就消失
- **系統管理員**：兩張卡片通常都是 0，因為系統企業一般沒有簽核流程與社群。
  平台的健康狀態不在這裡，在[主機設定](../02_platform_admin/server_settings.md)、
  [Redis 監看](../02_platform_admin/redis_monitor.md)與
  [本機登入錯誤監看](../02_platform_admin/login_failures_local.md)

## 常見問題

**待簽核顯示 0，但表單中心明明有我的待辦。**
儀表板只算「簽核」類任務。表單中心的待辦還包含退回給你修改的表單，那些不列入這個數字。

**卡片點不動。**
是設計如此，卡片只顯示數字。用左側選單前往對應功能。
