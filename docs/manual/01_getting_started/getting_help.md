# 取得說明與手冊

你正在讀的這份手冊有兩個入口，內容相同。

!!! abstract "作業：翻閱手冊"
    **MENU**：說明 ／ 使用者手冊

    1. 左側目錄依章展開
    2. 點頁面標題

!!! abstract "作業：查眼前這個畫面怎麼用"
    **MENU**：畫面右上角 [?]

    1. 按 [?]，會直接開到對應的手冊頁

## 目錄依你的身分過濾

站內的手冊目錄**只列出你用得到的頁面**：某個功能的選單對你不可見，
它的說明頁也不會出現在目錄裡。所以

- 不同帳號看到的目錄長度不一樣，這不是缺頁
- 整章的頁面都用不到時，那一章根本不會出現
- 這不是保密機制，只是為了不讓你被一堆用不到的說明干擾。
  所有頁面的完整版本也可由平台維運人員以離線網站的形式提供

## 畫面上看不出來的規則

- **[?] 只在已對應手冊頁的畫面上出現**。沒有 [?] 的畫面代表那一頁沒有專屬說明，
  請從目錄找
- 手冊以繁體中文為主，介面語言切到英文、日文或簡體中文時，有翻譯的頁面會顯示翻譯版，
  沒有的會顯示繁中版並在頁首提示
- 管理員的目錄最下方多一項「平台概念說明」，講帳號等級、角色、權限與安全機制的整體架構，
  一般成員看不到
- 安裝與第一次登入的說明不在這份手冊裡，因為那個階段還沒有帳號可以登入；
  它們放在安裝目錄的 `docs/install/`，用瀏覽器直接開即可

## 常見問題

**目錄裡沒有我要找的功能。**
先確認左側選單有沒有那個功能。選單沒有，代表你的身分或角色用不到它，說明頁也就不會列出。

**手冊講的畫面和我看到的不一樣。**
手冊描述的是目前版本的行為；若貴公司管理員改過選單名稱或位置，提示卡裡的選單路徑可能對不上，
以功能名稱為準。
