# 集團資料庫總覽

每個集團可以有一個**共享資料庫**，讓集團內各企業的流程把資料寫到同一個地方。
這一頁列出所有集團共享資料庫的狀態、容量、成員企業與異動歷程，**唯讀**，
沒有任何建立或刪除的按鈕。

!!! abstract "作業：檢查集團資料庫狀態"
    **MENU**：企業管理 ／ 集團資料庫總覽

    1. 看每張卡片右側的狀態標籤
    2. 點卡片標題列展開，看成員企業與異動歷程

集團與共享資料庫都是在[企業與合約管理](organizations.md)的 [集團設定] 建立的；
本頁只負責事後檢視。

## 三種狀態標籤代表什麼

| 標籤 | 意思 | 該怎麼處理 |
|---|---|---|
| 正常 | 平台有記錄，資料庫伺服器上也真的存在 | 不必處理 |
| 孤兒資料庫（橘框） | 資料庫伺服器上有一個名稱像集團資料庫的庫，但平台沒有對應記錄 | 多半是舊資料殘留或有人手動建的，確認無用後由資料庫管理員手動刪除 |
| 資料庫不存在（紅框） | 平台有記錄，但資料庫伺服器上找不到 | 先看下一節；真的被刪掉的話，該集團的流程同步會失敗 |

另外兩個標籤：「未就緒」表示建立過程沒有跑完；「集團停用」表示集團本身已停用，資料庫仍在。

## 畫面上看不出來的規則

!!! warning "全部變成「資料庫不存在」時，先懷疑主機設定，不要急著重建"
    本頁掃描資料庫伺服器時用的是主機 `.env` 裡的資料庫管理員連線設定。
    **那組設定缺少或連不上時，平台會查不到任何一個資料庫，於是每一張卡片都會被判成
    「資料庫不存在」、容量顯示 `-`**。這種情況集團的流程其實照常運作。
    判別方式：如果連正在使用中的集團也顯示紅框，幾乎可以確定是設定問題，不是資料真的不見了。

- **本頁只查容量，不查表數量**。要看集團資料庫裡有哪些表，得由資料庫管理員直接連進去
- 「Admin 帳號」負責建表改表，「Member 帳號」給各成員企業的流程讀寫資料用。
  兩組密碼由平台產生並加密保存，畫面上不顯示
- **成員企業之間的隔離靠資料列**：共享資料庫裡每張表都記錄「這一列屬於哪家企業」，
  任何成員都讀得到全部資料，但只能新增、修改、刪除自己企業的那些列
- 異動歷程只記「加入」與「退出」兩種動作，顯示最近 200 筆，展開卡片時才載入
- 成員清單是**目前**的成員，退出過的企業只會出現在異動歷程

## 常見問題

**集團解散了，資料庫會一起刪掉嗎？**
不會。解散集團後這裡會顯示「(集團已刪除)」，資料庫仍留在伺服器上。要不要刪由資料庫管理員決定，
平台不提供刪除按鈕。

**卡片顯示「無成員企業」。**
集團還在但所有企業都退出了，或建立集團時沒勾任何企業。資料庫本身不受影響。

**同一個集團可以有兩個共享資料庫嗎？**
不行，一個集團最多一個。[集團設定] 裡的 [建立共享資料庫] 對已經有資料庫的集團不會再建一個。
