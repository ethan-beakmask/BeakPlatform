# 本機登入錯誤監看

把平台上所有登入失敗事件攤開來看：誰在試、從哪裡試、試哪一家企業。
**這頁只看，不做任何處置**——它沒有封鎖或解鎖的按鈕。

!!! abstract "作業：看全平台的登入失敗狀況"
    **MENU**：本機安全 ／ 登入錯誤監看

    1. 「指定企業」保持 `-- 全部 (含未知網域) --`
    2. 按 [載入全部資料]

!!! abstract "作業：只看某一家企業"
    **MENU**：本機安全 ／ 登入錯誤監看

    1. 在「指定企業」選該企業（選了就自動載入）
    2. 需要看實際來源時，取消勾選「隱藏內網 IP」

## 先看這三件事，否則容易誤判

**一、時間範圍是固定的：上個月 1 號 00:00 到現在**，畫面右上角會顯示實際區間，
不能調整。所以月初看到的是將近兩個月的資料，月底則只有一個多月，
**跨月比較次數多寡沒有意義**。

**二、摘要數字是過濾後的結果。**「隱藏 Loopback」與「隱藏內網 IP」兩個勾選**預設都是開的**，
被藏起來的筆數顯示在同一列的右側（例如「(已過濾 14 筆)」）。
內部測試、健康檢查造成的失敗會被藏掉，這通常正是你要的；
但要盤點「總共被嘗試幾次」時，記得先取消勾選。

**三、系統管理員不會自動載入。**畫面一開始是空的，要按 [載入全部資料] 或先選一家企業。
企業管理員看的是[另一頁同名功能](../05_security_ops/login_failures.md)，
自動載入且只有自己企業的資料。

## 四種失敗類型代表的意思不一樣

| 標籤 | 發生了什麼 | 通常代表 |
|---|---|---|
| Unknown Domain | 登入網址帶的企業網域根本不存在 | 自動掃描，跟任何客戶都無關 |
| Unknown User | 企業存在，但沒有這個帳號 | 猜帳號，或員工用錯登入入口 |
| Wrong Password | 帳號存在、密碼錯誤 | 忘記密碼，或針對特定帳號的嘗試 |
| Denied | 帳號與密碼都對，但被擋下 | 帳號已鎖定、已停用，或不允許登入 |

`Detail` 欄會補上細節，例如密碼錯誤會附上該帳號累計的失敗次數，
被拒則會寫出拒絕的原因。

**`Unknown Domain` 只在「全部」模式下看得到**：它不屬於任何企業，
一旦在「指定企業」選了某家公司就會全部消失，摘要的「未知網域」卡片也會跟著隱藏。
平台對外開放時，這一類往往佔多數，屬於背景雜訊，重點是看它有沒有猜中真實的企業網域。

## 熱力圖的顏色是相對的

顏色深淺是拿**目前顯示範圍內單一小時的最高值**當滿格去分五級，不是固定的次數門檻。
因此同一格在 [近 10 天] 與另一個檔次下可能呈現不同顏色，
**不要用顏色比較兩個不同範圍的量級**，要比就看格子裡的數字與最右側的每日合計。

[近三個月] 這個檔次顯示的是**整個查詢區間的每一天**（也就是上個月 1 號至今）。

## 資料從哪裡來

來源是平台的稽核紀錄。認證事件（登入、登出、登入失敗）**在任何稽核等級下都會記錄**，
所以把[主機設定](server_settings.md)的稽核等級調到 MINIMAL 不會影響這頁。
反過來說，稽核資料被清理掉之後，這頁也就查不到那段時間了。

「Source IP」是平台判定出來的訪客位址。**平台前面有反向代理或 CDN 時，
若信任的代理位址沒設對，所有事件會塌縮成同一個來源**——
看到全部流量都來自單一位址時，先懷疑這件事，而不是真有人用固定 IP 猛打。

## 常見問題

**看到某個 IP 一直在猜帳號，可以在這裡封鎖它嗎？**
不行，這頁沒有處置功能。需要自動封鎖請走[資安案件處置中心](../05_security_ops/security_cases.md)。

**帳號被鎖定的人，要怎麼幫他解？**
鎖定會在等待期滿後自動解除。急用時由該企業的管理員重設他的密碼。

**「涉及帳號」數字比實際帳號數多。**
它算的是失敗事件裡出現過的帳號字串，包含根本不存在的帳號（猜測用的字串），
每一個不同的字串都算一個。

**同一家企業的失敗次數突然變多。**
先看類型：`Wrong Password` 集中在少數帳號多半是使用者自己忘記密碼；
`Unknown User` 大量出現且來源 IP 分散，才比較像是外部嘗試。
