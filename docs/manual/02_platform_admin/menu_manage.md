# 選單管理

這一頁管的是**全平台共用的一份選單結構**：項目的位置、階層、標題、圖示、啟用狀態。
每家企業看到的選單都長自這一份，**沒有企業專屬的選單結構**。
誰看得到哪一項，不在這裡設定，在[權限管理中心](access_center_system.md)。

!!! abstract "作業：調整選單位置"
    **MENU**：權限管理 ／ 選單管理

    1. 在樹狀清單直接拖曳項目到新位置（可跨層）
    2. 放開後自動儲存，底下狀態列顯示「順序已儲存」

!!! abstract "作業：新增一個分類群組"
    **MENU**：權限管理 ／ 選單管理

    1. 按 [+ 新增根項目]
    2. 輸入標題，按 [建立]
    3. 拖曳其他項目到它底下

!!! abstract "作業：改標題、圖示或停用某個項目"
    **MENU**：權限管理 ／ 選單管理

    1. 該列按 [編輯]
    2. 改標題（含各語系）、圖示、父選單、顯示順序、預設展開、啟用
    3. 按 [儲存變更]

## 這頁能改什麼、不能改什麼

| 能改 | 不能改 |
|---|---|
| 位置、父子關係、顯示順序 | 連結類型與連結目標（由程式或模組決定） |
| 標題（繁中、英文、簡中、日文）、圖示 | 預設選單的刪除 |
| 預設展開、啟用／停用 | 鑰匙 1 與鑰匙 2（在權限管理中心） |
| 自建群組的新增與刪除 | 路由型項目的新增（由平台安裝與模組同步建立） |

- **手動只能新增「群組標題」型的根項目**，它不可點擊，用途是把其他項目收納在底下。
  真正可點的路由型項目一律由平台或模組自動建立
- 新建的群組**只對系統管理員可見**，要讓別的身分看到，去權限管理中心開鑰匙 1
- **預設選單不能刪**，只能停用；自建群組可以刪，但它底下若還掛著預設選單就會被擋，
  要先把那些項目拖出去
- 停用只是不顯示，**不改變任何人的存取權限**；反過來，把項目搬到別的群組下也不會改變權限

## 列的底色與四個勾選欄

清單每列依「哪些身分看得到」上色，四個勾選欄是鑰匙 1 的現況（只能看，要改去權限管理中心）：

| 底色 | 意思 |
|---|---|
| 紅 | 只有系統管理員看得到 |
| 藍 | 只有企業管理員看得到 |
| 黑 | 企業成員可見，或三種以上身分共用的固定項目 |
| 黃 | 外部廠商 |
| 紫 | 模組選單，可見性另外受模組使用權控制 |

四種身分是**平行的**，不是階層：系統管理員也只看得到勾了「系統」的項目，
企業管理員看不到只勾「企業成員」的項目。

## 三個重置按鈕的差別

| 按鈕 | 動到什麼 | 不動什麼 |
|---|---|---|
| 重置MENU項目位置 | 預設選單的位置、父子關係 | 標題、圖示、啟用、鑰匙；自建群組 |
| 設定目前組態成出廠值 | 把現況存成新的出廠快照（不改任何選單） | 自建群組不會進快照 |
| 重置MENU所有設定成出廠值 | 預設選單的位置、標題、圖示、連結、啟用、鑰匙 1、鑰匙 2，全部覆蓋回快照 | 自建群組 |

!!! warning "「設定目前組態成出廠值」快照的鑰匙 2 取自系統企業"
    鑰匙 2 是每家企業各自一份的。快照時平台只記錄**系統企業**的鑰匙 2 設定（以角色代碼記錄），
    重置時再依角色代碼套到**每一家**企業。所以要把某個鑰匙 2 設定變成出廠值，
    得先在系統企業上設好再快照，在某家客戶企業上設的不會進快照。

- 沒存過快照時，重置用的是程式內建的出廠值
- 重置出廠值會**覆蓋所有企業的鑰匙 2**，執行前確認框會列出影響範圍，請看清楚再按
- 三個動作完成後頁面會自動重新整理

## 常見問題

**拖曳後狀態列顯示「儲存失敗」。**
位置沒有存進去，重新整理頁面會回到原狀。多半是同一時間有另一位系統管理員也在改，重試即可。

**新增的模組沒有出現在選單裡。**
模組選單由模組同步建立，不是在這裡加。到主機上執行模組同步指令後再回來看。

**某個項目不小心停用了，員工找不到。**
按 [編輯] 重新勾選「啟用」即可，員工重新整理頁面就看得到；停用期間他們的權限並沒有被拿掉。
