# 系統管理員帳號

系統管理員是**平台自己的帳號**，隸屬系統企業（頁面副標會顯示它的網域），
不屬於任何一家客戶企業。這頁只管這種帳號，客戶的管理員請到
[企業與合約管理](organizations.md)的 [管理員管理] 處理。

!!! abstract "作業：新增系統管理員"
    **MENU**：權限管理 ／ 系統管理員帳號

    1. 按 [+ 新增系統管理員]
    2. 填帳號、Email、顯示名稱
    3. 填密碼（可按 [建議密碼] 產生），再填一次確認
    4. 按 [建立帳號]

!!! abstract "作業：重設某人的密碼或停用帳號"
    **MENU**：權限管理 ／ 系統管理員帳號

    1. 左側點該帳號
    2. 改「狀態」，或在「變更密碼」填新密碼
    3. 按 [儲存變更]

!!! abstract "作業：刪除帳號"
    **MENU**：權限管理 ／ 系統管理員帳號

    1. 左側點該帳號
    2. 捲到最下方，按 [刪除帳號]

## 建立後就改不掉的兩個欄位

**帳號**與 **Email** 建立後不可變更，編輯面板上是唯讀的。
打錯字只能新建一個正確的、再刪掉錯的。可以改的只有顯示名稱、狀態與密碼。

其他限制：

- 帳號只能用英數字與底線，登入時要寫成 `帳號@系統企業網域`
- **Email 不受公共信箱網域的限制**，可以用 Gmail 這類信箱（客戶企業的帳號不行）
- 密碼至少 12 碼

## 有三道防呆，都是為了不讓平台鎖死

| 動作 | 限制 |
|---|---|
| 停用自己 | 不允許，狀態欄會直接顯示「不能停用自己」 |
| 刪除自己 | 不允許，自己的帳號不會出現刪除區塊 |
| 刪除別人 | 平台至少要留一個**啟用中**的系統管理員，只剩一個時擋下 |

!!! warning "建議至少保留兩個啟用中的系統管理員"
    這頁沒有自助救援入口。全部的系統管理員都失效（忘記密碼、離職、同時被鎖）時，
    只能由維運人員在主機端處理。平時多留一個備用帳號，就能互相重設密碼。

刪除是**不可復原**的，畫面上不會再出現該帳號。但它占用的帳號名與 Email 會釋出，
之後可以重新建立同名帳號（那是一個全新的帳號，不會接回原本的紀錄）。

## 這種帳號能做什麼、不能做什麼

系統管理員的權限在**平台層**：開通企業與合約、模組管理、主機設定、系統層的權限骨架。
它**不是任何企業的管理員**——客戶企業的部門、角色、成員帳號等，
仍要由該企業自己的管理員設定。

兩種身分是分開的帳號，不能互相轉換：需要一個能操作某企業日常事務的帳號時，
請在該企業裡另建帳號，而不是把系統管理員加進去。

## 常見問題

**「最後登入」是空白的。**
表示這個帳號建立後從未登入過。剛建好的帳號都是這樣。

**要怎麼確認某個系統管理員多久沒用了？**
點選該帳號，右側「帳號資訊」有建立時間、最後登入、密碼變更時間三個時間戳。

**同事忘記密碼，可以自己解嗎？**
可以：由另一個系統管理員在這頁直接填新密碼並儲存，然後把新密碼交給他。
密碼變更後不會強制他下次登入時再改一次，需要的話請口頭提醒。

**帳號被鎖定了怎麼辦？**
鎖定是密碼連續錯誤造成的，等待期滿會自動解除；急用時由另一個系統管理員重設密碼即可。
