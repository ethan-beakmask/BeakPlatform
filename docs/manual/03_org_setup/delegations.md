# 代理授權

主管休假、出差時，由管理員指定代理人接手簽核。生效期間內，授權人能簽的單，
代理人在表單中心的待簽清單也看得到、也能簽。成員沒有自助設定代理的頁面，一律由管理員在這裡設定。

!!! abstract "作業：建立代理"
    **MENU**：帳號管理 ／ 代理授權

    1. 按 [新增代理授權]
    2. 選授權人（休假的主管）、被授權人（代理的人）
    3. 代理類型選「全權代理」
    4. 填生效開始、生效結束；授權原因選填
    5. 按 [建立代理授權]

!!! abstract "作業：提前結束"
    **MENU**：帳號管理 ／ 代理授權

    1. 該筆按 [查看]
    2. 最下方填撤銷原因，按 [撤銷代理授權]。撤銷後不能恢復，要再用時重建一筆

!!! abstract "作業：改日期或類型"
    **MENU**：帳號管理 ／ 代理授權

    1. 該筆按 [編輯]，改完按 [儲存變更]；狀態會依新的日期重新判定

## 代理類型：要代理簽核請選全權代理

| 類型 | 簽核時的效果 |
|---|---|
| 全權代理 | 授權人能簽的單，代理人都能簽 |
| 限額代理 | 沒填金額上限時等同全權代理；**填了金額上限，代理人不會拿到任何簽核權**（平台在簽核時取不到單據金額，無法比對上限） |
| 特定代理 | **目前不生效**，代理人不會拿到簽核權 |

## 生效與狀態

- 狀態依生效期間判定：開始日在未來是「待生效」、期間內是「生效中」、過了結束日是「已過期」；撤銷過的永遠是「已撤銷」
- 只有「生效中」而且今天在期間內的授權，代理人才拿得到簽核權
- **狀態只在儲存時判定，不會每天自動更新。** 提前建立的「待生效」授權到了開始日不會自己變成「生效中」，
  請在生效期間內進編輯頁再按一次 [儲存變更]，或等到開始日當天再建立。
  反過來，過了結束日的授權在列表上仍顯示「生效中」直到下一次編輯，但代理人實際上已經簽不了
- 已撤銷、已過期的不能編輯，列表上也不會有 [編輯]
- 授權人與被授權人建立後不能改，要換人就撤銷後重建
- 下拉只列啟用中的成員

## 代理人簽核時

- 授權人的待簽單會出現在代理人的表單中心待簽清單；代理人自己本來就能簽的單不受影響
- 簽核紀錄上記的是實際按下按鈕的人（代理人），不會另外標示「代理自誰」；要追溯請對照這裡的授權與撤銷紀錄
- 代理只涵蓋簽核。授權人的其他權限（選單、模組、管理功能）不會轉給代理人
- 一個人可以同時代理多位授權人；同一位授權人也可以有多個代理人

## 常見問題

**代理人看不到主管的單。**
依序檢查：類型是不是全權代理（或未填金額的限額代理）、狀態是不是「生效中」（待生效的要編輯儲存一次）、
今天在不在期間內、代理人帳號是否啟用。

**撤銷後想恢復。**
不能，重建一筆。

**[撤銷授權] 與 [刪除紀錄] 的差別。**
撤銷會留下撤銷者、時間、原因，稽核時看得到；[刪除紀錄] 在編輯頁的危險區域，會把整筆從列表移除。
稽核用途一律用撤銷。
