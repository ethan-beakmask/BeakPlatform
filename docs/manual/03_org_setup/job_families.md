# 職系設定

職系是**職涯軌道**：管理職（帶人）與專業職（不帶人），專業職底下再分業務、客服、行政、工程等。
它與[職等](job_levels.md)交叉出[職稱](job_titles.md)。

!!! abstract "作業：建立職系"
    **MENU**：職級職稱 ／ 職系設定

    1. 按 [+ 新增職系]
    2. 填名稱、選類型（管理職／專業職）；要掛在某個職系底下就選「上層職系」
    3. 按 [建立職系]

!!! abstract "作業：修改、停用、刪除"
    **MENU**：職級職稱 ／ 職系設定

    1. 點樹狀表格中的那一列，開啟編輯視窗
    2. 改完按 [儲存變更]；停用就取消勾選「啟用」
    3. 要刪除按編輯視窗裡的 [刪除]

## 只有兩層，而且只有末端能掛職稱

- 樹只有兩層：**根職系**與它底下的**子職系**。「上層職系」下拉只列根職系，子職系不能再往下分
- **職稱只能掛在末端職系**（沒有子職系的那些）。職稱設定的職系下拉與矩陣的欄位都只列末端職系
- **根職系一旦新增了子職系，原本直接掛在它上面的職稱會從職稱設定頁與矩陣上消失**，資料還在但畫面上找不到。
  要細分一個已經有職稱的職系，順序是：先把它的職稱移到別的末端職系（[矩陣](job_matrix.md)拖拉最快）
  → 建子職系 → 再把職稱搬回子職系
- 類型（管理職／專業職）只是分類顏色，不影響任何功能；職稱是否帶人在職稱自己的「帶人主管」勾選
- 代碼留空自動產生，建立後不能改；排序數字小的在前

## 停用與刪除

- **停用職系**：它底下的職稱在職稱設定頁會被歸到「未分類」群組，矩陣上整欄消失；職稱本身不會被停用
- **刪除有子職系的根職系**會被擋，先刪子職系
- **刪除底下有職稱的職系**會問「是否連同職稱一併刪除」，同意就把那些職稱一起刪掉。
  **這個連動刪除不檢查職稱是否已指派給成員**，刪之前先到[職位設定](positions.md)確認沒有人掛著那些職稱

## 常見問題

**新增子職系後，職稱設定頁少了一整批職稱。**
它們原本直接掛在那個根職系上（見上面第三點）。先刪掉剛建的子職系讓它們現形，把職稱搬到別處，再重建子職系。
