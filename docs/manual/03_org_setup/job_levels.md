# 職等設定

職等是**高低順序**：總經理級、經理級、職員級這類層級，用「序號」排大小。
它本身不是頭銜，頭銜是[職稱](job_titles.md)（職等＋職系的組合）。整組關係見[職級職稱矩陣](job_matrix.md)。

!!! abstract "作業：建立職等"
    **MENU**：職級職稱 ／ 職等設定

    1. 按 [+ 新增職等]
    2. 填名稱與序號（數字越大越高），要當主管層級就勾「管理職」
    3. 按 [建立職等]，新的一列出現在左邊表格並直接進入編輯

!!! abstract "作業：修改、停用、刪除"
    **MENU**：職級職稱 ／ 職等設定

    1. 點左邊表格的一列，右邊出現編輯欄位
    2. 改完按 [儲存]；要停用就取消勾選「啟用」再按 [儲存]
    3. 要刪除按 [刪除]，會再確認一次

## 序號怎麼給

- **序號決定高低，數字越大職等越高**，範圍 0 到 9999，表格永遠由高排到低
- **用等距跳號**：100、200、300……900。日後要在兩級之間插一級，直接用 150、250 這種中間值，
  不必把既有職等全部改號
- 序號不檢查重複。兩個職等同序號時，表格與矩陣的列順序不固定，避免這樣設
- 建議代碼寫成「L＋序號」（L100、L150），留空會依名稱自動產生；**代碼建立後不能改**
- 「管理職」與「管理幅度」只是標示。管理職會在矩陣上顯示「管理」標記，
  並在[矩陣](job_matrix.md)拖拉職稱時決定職稱的「帶人主管」旗標；它不會賦予任何系統權限

## 停用與刪除的差別

| | 停用 | 刪除 |
|---|---|---|
| 有職稱掛在這個職等 | 可以，但會先列出啟用中的職稱要你確認 | 擋下，訊息會說有幾個職稱使用中 |
| 之後還看得到嗎 | 左邊表格變灰字，仍可點開改回啟用 | 從表格消失，不能復原 |
| 對既有職稱的影響 | 職稱仍掛著它，但職稱設定與矩陣的下拉選不到它、矩陣少一列 | 要先把職稱改到別的職等或刪掉才刪得了 |

刪除要清的是「所有未刪除的職稱」，包含停用中的職稱；停用時只計算啟用中的。

## 常見問題

**新企業一進來這頁是空的，有沒有範本？**
沒有出廠職等，要自己建。常見的十級制參考：0 約聘、100 職員、200 高級職員、300 主任、
400 副理、500 經理、600 副處長、700 處長、800 副總經理、900 總經理。

**想在經理（500）和處長（700）之間加一級。**
新增一個序號 600 的職等即可，其他都不用動。
