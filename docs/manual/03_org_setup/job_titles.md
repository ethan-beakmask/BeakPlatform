# 職稱設定

職稱是成員的**正式頭銜**，每個職稱固定屬於一個[職等](job_levels.md)與一個[職系](job_families.md)：
經理＝經理級＋管理職，專案經理＝經理級＋工程技術職。

!!! abstract "作業：建立職稱"
    **MENU**：職級職稱 ／ 職稱設定

    1. 按 [+ 新增職稱]
    2. 填名稱，選職等與職系；會帶人的勾「帶人主管」
    3. 按 [建立職稱]，職稱會出現在所屬職系的群組底下

!!! abstract "作業：修改、停用、刪除"
    **MENU**：職級職稱 ／ 職稱設定

    1. 點職稱那一列（職系群組列點了沒有反應）
    2. 改完按 [儲存變更]；停用就取消勾選「啟用」
    3. 要刪除按編輯視窗裡的 [刪除]

## 畫面上看不出來的規則

- 職系下拉只有**末端職系**可選；職等下拉只有**啟用中**的職等，由高到低
- 「帶人主管」是職稱自己的旗標，與職等的「管理職」、職系的「管理職」類型互不連動。
  **唯一的例外是在[矩陣](job_matrix.md)拖拉**：拖過之後，這個旗標會被重設成所在職等的「管理職」設定
- 兩個職稱可以同名（例如專業職與工程技術職各有一個「專案經理」），靠代碼區分；代碼建立後不能改
- 「未分類」群組＝職稱掛的職系已停用。把職系重新啟用，或把職稱改到別的職系，它就會歸位
- 職系只能在沒有直掛職稱時新增子職系，所以正常情況下不會有職稱掛在「有子職系的根職系」上；
  若是早期資料造成，那些職稱不會顯示在這頁（頁尾的總數仍會算進去），處理方式見[職系設定](job_families.md)
- 停用的職稱：[職位設定](positions.md)的下拉選不到、矩陣不顯示；已經指派出去的職位不受影響

## 停用與刪除

- **刪除**：只要還有成員的職位掛著這個職稱（包含已停用的職位指派），就會被擋。
  先到[職位設定](positions.md)刪掉那些指派
- **停用**不做任何檢查

## 常見問題

**下拉裡找不到某個職系。**
它有子職系（只能選它的子職系），或它被停用了。

**同一個頭銜要出現在兩個職系。**
建兩個職稱，名稱一樣、代碼不同，各掛一個職系。
