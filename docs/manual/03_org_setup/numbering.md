# 編號設定

定義企業內各種編號怎麼產生：成員編號、廠商編號、表單單號、管理員編號，
以及門禁卡、資產這類自訂編號。新企業出廠已有六條規則，多數情況直接用，不必先改。

!!! abstract "作業：新增一條規則"
    **MENU**：帳號管理 ／ 編號設定

    1. 按 [+ 新增規則]
    2. 填規則名稱、選使用範圍
    3. 勾要用的元素（前綴、年碼、月碼、後綴），序號一定有；拖曳左側把手調整前後順序
    4. 按 [編號預覽] 看前 10 個號碼長什麼樣
    5. 要當預設就在「預設用途」選；按 [建立規則]

!!! abstract "作業：更換某種用途的預設規則"
    **MENU**：帳號管理 ／ 編號設定

    1. 編輯要成為預設的那一條
    2. 「預設用途」選對應用途，按 [儲存變更]；原本的預設會自動變成非預設

!!! abstract "作業：停用或刪除"
    **MENU**：帳號管理 ／ 編號設定

    1. 停用：編輯頁取消勾選「啟用此規則」，儲存。停用的規則不再出現在新增帳號的下拉
    2. 刪除：列表按 [刪除]。預設規則不能刪，先在編輯頁把預設用途改回「非預設」

## 出廠的六條規則

| 規則 | 第一個號碼 | 預設用途 |
|---|---|---|
| 預設企業成員編號 | `0001` | 企業成員預設 |
| 預設企業管理員編號 | `ADM001` | 企業管理員預設，只在建立企業時給原始管理員取號 |
| 外部廠商編號 | `賓0001(臨)` | 外部廠商預設 |
| 預設表單編號 | `Form-260900001` | 表單預設，序號每月重置 |
| 行政資產編號 | `ADMN-260001` | 非預設 |
| 門禁卡實體卡號 | `0001` | 非預設，使用範圍「內外都通用」 |

## 元素怎麼組

| 元素 | 說明 |
|---|---|
| 前綴／後綴文字 | 逗號分隔可填多個（`天,地,玄,黃`）。序號用完就進到下一個文字，最後一個用完回到第一個 |
| 公元年碼 | `2026`、`26` 或 `6` |
| 年換算碼 | 公元年加上運算值再補零：運算值 `-1911`、3 位 → `115`（民國年） |
| 月碼 | `09` 或 `9` |
| 序號 | 位數、起始值、重置週期（永不／每年／每月）。一定要有 |

- 年、月取產生號碼**當下**的日期
- 「編號長度」填 0 不限制；填了就必須等於各元素長度加總，否則存不了
- 每年或每月重置：序號從起始值重來。**但同一企業內編號不能重複**，重置後撞到之前發過的號碼會被自動跳過，
  所以有設重置週期的規則要搭配年碼或月碼
- 起始值只在序號還沒走到那裡時有效；已經發到 0050 再把起始值改成 0100，下一個號碼仍是 0051

## 使用範圍與預設用途

- **使用範圍**決定規則出現在哪個新增畫面的下拉：內部專用 → 企業成員帳號；外部專用 → 外部廠商帳號；
  內外都通用 → 只在[部門設定](departments.md)頁快速新增成員時可選
- **預設用途**每種只能有一條，新設定的會把原本那條擠掉。用途決定哪條規則在建立帳號時被自動選用、
  表單送出時自動編號
- 表單預設：表單送出時若配對沒有指定規則就用它。沒有表單預設時單號會是 `FORM-日期-流水號` 的固定格式
- 企業管理員預設只在建立企業時用一次，之後新增的管理員不會自動取號，見[企業管理員](org_admins.md)

## 號碼不會回收

- 自動取的、手動輸入的號碼都會記在「已用號碼」清單，**刪除帳號不會釋放號碼**
- 列表的「編號預覽」是下一個真正會發出的號碼；編輯頁的 [編號預覽] 是從頭模擬的格式示範，不代表目前進度
- 序號、前綴、後綴全部循環完就發不出號碼，建立帳號時會失敗並顯示「所有編號都已用完」。
  加大序號位數或加前綴文字即可

## 常見問題

**新增成員頁的下拉沒有我的規則。**
使用範圍要是「內部專用」且啟用中。只有一條符合時不會出現下拉，直接套用。

**號碼中間跳號。**
中間那個號碼被手動輸入過，或被已刪除的帳號用過，系統自動跳過。

**按 [+ 新增外部廠商] 被導到這一頁。**
沒有「外部廠商預設」規則。建一條使用範圍「外部專用」的規則並把預設用途設為外部廠商。
