# 基本班表

定義企業成員的標準上班時間與假日。一家企業可以有多張班表（不同地區、不同時區各一張），
其中一張是預設，成員沒有指定班表就套用預設。

!!! abstract "作業：建立班表"
    **MENU**：帳號管理 ／ 基本班表

    1. 按 [+ 新增班表]
    2. 填班表代碼（建立後不能改）、班表名稱、時區
    3. 週一到週日各選「上班」或「休息」；上班日選起訖時間，按 [+ 休息] 加午休，最多三段
    4. 想一次套用就勾「將目前設定的第一個上班日時間複製到所有上班日」
    5. 要當預設就勾「設為企業預設班表」，按 [儲存]

!!! abstract "作業：設定假日與補班"
    **MENU**：帳號管理 ／ 基本班表 ／ [假日設定]

    1. 點月曆上的日期，或按 [+ 新增假日]
    2. 填開始日期、結束日期（留空只設一天），類型選「假日」「補假」或「補班」（補假視同休假，也會出現在企業行事曆上）；
       補班要填工作時段，例如 `09:00-12:00,13:00-17:00`
    3. 按 [儲存]
    4. 要取消：同樣選日期範圍，勾「取消設定（回復班表預設值）」再按 [確認取消設定]

!!! abstract "作業：指定某位成員的班表"
    **MENU**：帳號管理 ／ 企業成員帳號 ／ [編輯]

    1. 「班表」下拉選班表；留「使用企業預設」就跟預設班表走
    2. 按 [儲存變更]

## 畫面上看不出來的規則

- 預設班表只有一張，[設為預設] 會取消原本的預設。**預設班表不能刪除**
- 已指派給成員的班表不能刪，訊息會顯示人數；先到成員編輯頁把他們換掉
- 時間以 30 分鐘為單位。跨午夜的班（22:00 到 06:00）可以設，工時計算會處理跨日
- 假日設定蓋過週間設定：設成假日那天就不上班、設成補班那天照填的時段上班，不管那天原本是不是上班日
- 選的日期範圍若包含班表本來就休息的日子（例如週末），儲存時會問要不要一起設；一起設只是多一筆標記，結果不變
- 同一天只能有一筆設定；已設定的日期在批次匯入時會略過
- 假日是**每張班表各自設定**，兩張班表要各設一次
- [匯入台灣假日] 只有 2026 年的資料，其他年份要自己設或逐日新增
- 目前平台的流程逾時與 SLA 倒數都以日曆時間計算，尚未扣除班表的非工作時間；班表現階段的作用是記錄各成員的標準工時與假日

## 常見問題

**成員沒有指定班表會怎樣。**
套用預設班表。沒有預設班表就等於沒有工時資料。

**想刪班表，卻說已指派給幾位成員。**
到企業成員帳號逐一編輯，把「班表」改成別張或「使用企業預設」，再回來刪。

**補班日要填幾個時段。**
一段或多段都可以，用逗號分隔，格式 `HH:MM-HH:MM`。留空存不了。
