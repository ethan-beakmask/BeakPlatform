# AI 用量與配額

看[AI 分析節點](ai_agent_node.md)這個月用了多少、被擋了幾次，並設定貴公司自己的上限。

!!! abstract "作業：調整企業配額"
    **MENU**：表單流程 ／ AI 用量與配額

    1. 在「配額設定」改要調整的項目
    2. 按「儲存」

    不想再自訂某一項時按該項的「回復系統預設」。

## 三個區塊

**當期用量**——今日與本月各自的執行次數、估算成本，以及「本月被配額擋下」的次數。
每張卡上會標出這個期間是從什麼時候起算的。

**配額設定**——五個項目。**0 表示不限**。沒有自訂的項目顯示「系統預設」，
沿用平台給的值（畫面上會標出該值是多少）。

| 項目 | 擋什麼 |
|---|---|
| 允許使用 AiAgent 節點 | 關掉之後，整個企業的 AI 分析節點都不執行 |
| 每日／每月執行次數上限 | 次數 |
| 每日／每月估算成本上限（USD） | 花費 |

**執行明細**——每一次執行一列，可依狀態與日期區間篩選。點列首的箭頭展開，
可看到這次用到的每個模型各自的用量。

## 畫面上看不出來的規則

### 成本是估算，不是帳單

「估算成本」是依標準 API 牌價換算出來的等值金額，用途是相互比較與配額判定。
**它不是實際扣款金額**，也不等於訂閱制方案的帳單。

### 明細的 tokens 只算主模型，成本卻是全部模型的

一次分析可能不只用到一個模型。表格的「主模型 tokens」欄只是主要那一個的用量，
**估算成本則已包含全部模型**。要看完整用量請展開該列。

兩欄口徑不同是刻意的，不要拿 tokens 去回推成本。

### 四種狀態，只有「已擋下」不佔額度

| 狀態 | 意思 | 佔額度 |
|---|---|---|
| 執行中 | 已取得名額，正在跑或還沒回報結果 | 是 |
| 成功 | 分析完成 | 是 |
| 失敗 | 有嘗試執行但沒成功 | 是 |
| 已擋下 | 配額或開關擋下，根本沒有執行 | 否 |

失敗也算額度，因為呼叫本身通常已經產生成本。

### 配額擋下時，流程節點一律算錯誤

被擋下的那一次，AI 完全沒有看過這張單。所以節點會走錯誤路徑，
**不會因為節點設了「AI 失敗時：繼續流程」而放行**——否則簽核者會誤以為 AI 已經分析過。

### 日與月的分界依企業時區

「今日」「本月」是用貴公司設定的時區換算的，不是伺服器時間。
每張卡上標的「期間起點」就是實際的起算時刻。

### 同一個節點被擋，只會記一筆

流程遇到錯誤會自動重試，但重試造成的「已擋下」不會重複累計，
所以「本月被配額擋下」的次數不會因為重試而灌水。

## 常見問題

**次數比實際用的多一次，狀態停在「執行中」**——服務在該次分析途中被重新啟動，
那筆記錄沒有機會回報結果。它會繼續佔一次額度到期間結束，屬於已知行為；
影響到作業時，可以先把當期上限調高。

**改了配額但節點還是被擋**——先確認擋下的原因：明細的「錯誤訊息」會寫是哪一項超限
（每日次數、每月成本…）。每月的上限不會因為調整每日上限而放寬。

**想完全停用 AI 分析**——把「允許使用 AiAgent 節點」關掉即可，流程不必改。
