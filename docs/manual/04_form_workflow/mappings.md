# 配對管理與發行

把一張表單和一個流程綁在一起，發行之後使用者才能在表單中心送單。

!!! abstract "作業：配對並發行"
    **MENU**：表單流程 ／ 配對管理

    1. 按「+ 新增配對」，選表單、選流程，按「建立配對」
    2. 在該列按「新發行」
    3. 按「權限」設定誰可以填這張表單

```mermaid
flowchart LR
    A[建立配對] --> B[新發行]
    B --> C[設定填寫權限]
    C --> D[使用者在表單中心送單]
```

## 發行是「複製一份快照」

按下新發行的當下，平台把表單與流程的設計**複製**到發行庫。之後：

- 使用者送的單，跑的是快照，不是設計圖
- 改了設計沒有重新發行，**等於沒改**，而且沒有任何提示
- 已經送出的單，繼續用它當初那一版跑完，不會被新版影響

**還沒發行過的配對是例外**：它直接採用設計圖，永遠是最新的。這是給設計者邊改邊測試用的，
所以未發行的配對只有管理員能用。也因為設計圖只有一份，改過設計之後，
表單中心裡那些測試舊記錄與新設計對不起來是正常的，不必追。

需要讓一般使用者在真實環境試用時，做法是**另開一個配對**發行給指定的人，
原本的配對照舊運作，兩者互不干擾。

## 版本清單

按「版本」看這個配對發行過的所有版本，可以對每一版做：

| 動作 | 說明 |
|---|---|
| 暫停 | 暫時不讓人用這一版，可再「開放」 |
| 封存 | 收起來不再使用 |
| 刪除 | **已被使用過的版本、以及運作中的版本刪不掉** |

## 填寫權限預設不含企業管理員

新配對沒有任何權限規則時，能填的只有系統管理員與表單／流程設計者角色。
**企業管理員自己也不在裡面**，這時送單會拿到「您沒有填寫此表單的權限」。

發行完一定要按「權限」加規則，可以指定部門（可含子部門）、社群（可含下層）、
角色或個人。

## SQL 同步：啟用之後關不掉

版本清單裡每一版有一個「SQL 同步」開關。打開之後，該版表單的資料會在**流程結束時**
寫進貴公司的獨立資料庫，供報表或 BI 直接查詢。

!!! danger "先確認再開"
    **啟用後不可關閉。** 平台會自動建立企業資料庫與對應的資料表，
    這個決定沒有畫面上的還原路徑。

幾件事先知道：

- 只有**已發行**的版本能啟用；已封存的版本不能
- 每次「新發行」都會自動為新版本建一張新表，舊表留著
- 寫入時機是**流程結束**（核准、退回、取消、錯誤都算），寫進去的是最終資料，
  含簽核過程中被改過的值。所以簽核途中在資料庫查不到那張單，這是正常的
- 資料表名稱顯示在版本清單的「資料表名稱」欄

## 常見問題

**表單中心看不到這張表單**——三個原因依序查：配對還沒發行、發行版本被暫停或封存、
這個帳號不在填寫權限內。

**改了表單欄位，使用者送的單還是舊版面**——沒有重新發行。

**同名的表單和流程沒有自動配對**——平台刻意不自動配對，避免建出非預期的組合，
一律手動建立。

**一個流程可以給幾張表單用**——不限。同一個流程可以被多張表單配對。
