# 資安監控團隊規劃

處置流程與角色編制要一起規劃：流程決定「案件會走到誰手上」，
角色決定「誰看得到、誰簽得了」。兩邊對不上時，最常見的症狀是
案件停在某個節點沒有人能處理。

建議先讀[資安事件處置流程](workflow_variants.md)挑一個適合貴組織值班編制的版本，
再依[資安團隊角色設計](role_design.md)把流程需要的角色建起來並指派人員。
