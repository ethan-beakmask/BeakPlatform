# 企業行事曆與我的行事曆

把企業裡「跟時間有關的事」放在同一個月曆上看：公司放假與補班、誰在代理誰、
限期的兼任或代理職位、系統公告、你手上等著簽的單，以及你自己登記的請假、出差與會議。
除了個人事件與企業事件可以在這裡新增，其餘資料都來自既有功能（班表、代理指派、職位、公告、表單流程），
在那些頁面改了，行事曆會跟著變。

!!! abstract "作業：看企業行事曆"
    **MENU**：行事曆 ／ 企業行事曆

    1. 進頁面預設是本月的月視圖，今天的日期有外框
    2. 按 [<] [>] 換月，按 [今天] 回到本月；按 [週] 切成一週七欄，看得到每筆的時段
    3. 點任一天的格子，跳出當日明細；有 [開啟] 連結的事件可以直接跳到來源頁
    4. 右上角 [我的行事曆] 切到個人視圖

!!! abstract "作業：登記自己的請假、出差或會議"
    **MENU**：行事曆 ／ 我的行事曆

    1. 按右上角 [新增事件]，或先點某一天再按明細底下的 [在這天新增]（會預填成那一天的全天事件）
    2. 選類型（請假／出差／會議／其他）、填標題；勾 [全天事件] 就只填日期，不勾則填開始與結束時間
    3. 選可見性：**公開**（同事看得到標題與內容）／**僅顯示已排程**（同事只看到你那個時段有安排）／**私人**（只有你自己看得到，管理員也看不到）
    4. 按 [儲存]。點那一天的明細，自己的事件旁有 [編輯] 與 [刪除]

    請假與出差會同步扣掉你的班表工作時段：全天事件整天不計工時，非全天只扣掉那個時段，
    改期或刪除事件時班表也會跟著更新。若這段期間你是某些簽核流程的簽核者，
    記得替自己設定代理人：到「個人設定 ／ 我的代理指派」；管理員要替別人設定，到「權限管理中心 ／ 帳號配角色」
    （行事曆目前不會自動建立代理）。

!!! abstract "作業：建立企業事件（管理員）"
    **MENU**：行事曆 ／ 企業行事曆

    1. 按右上角 [新增企業事件]，或點某一天後按 [在這天新增]
    2. 選類型（會議／企業活動／其他）、填標題與期間
    3. 企業事件一律對全企業公開，沒有可見性選項；建好後管理員可在明細裡 [編輯] 或 [刪除]

    企業假日與補班仍在「帳號管理 ／ 基本班表」維護，行事曆只負責顯示。

## 兩個視圖看到的東西不一樣

| 內容 | 企業行事曆 | 我的行事曆 |
|---|---|---|
| 企業預設班表的假日、補假、補班（含非工作日底色） | 有 | 有（改用你自己的班表；沒指定就用企業預設） |
| 代理指派期間 | 只有被代理人、代理人與管理員看得到 | 同左 |
| 有期限的職位（兼任、代理、臨時） | 管理員看全部；一般成員只看自己的 | 你自己的 |
| 公告（跑馬燈公告的有效期間、緊急廣播的發布日） | 有 | 有 |
| 你待簽核的單 | 不顯示 | 不顯示（待簽核沒有確定時間，屬於待辦；請到表單中心的「待簽核」處理） |
| 流程的等待到期（Delay 節點） | 只有管理員看得到 | 不顯示 |
| 你自己的個人事件（請假、出差、會議） | 依你自己的可見性設定顯示給同事 | 有，可編輯／刪除 |
| 其他成員的個人事件 | 依對方設定：公開才看得到內容，否則只看到「已排程」與時段；設成私人的完全不顯示 | 不顯示 |
| 企業事件（管理員建立） | 有 | 有 |

## 「已排程」是什麼

其他成員把個人事件設成「僅顯示已排程」時，你只看得到他在那個時段有安排，看不到標題與內容。
同一個人在重疊或相接的時段有好幾筆，會合併成一格「已排程」，所以看不出他有幾件事。
設成「私人」的事件則完全不會出現，**管理員也看不到**。

## 日期怎麼算

所有日界都依企業設定的時區（畫面標題下方有標）。跨時區的成員看到的日期與企業一致，
不會因為瀏覽器所在地不同而差一天。
假日與補班來自各班表的假日設定；國定假日由管理員在「基本班表」的假日表取得或上傳後發佈。

## 常見問題

**只有星期六、日有非工作日底色，平日的國定假日沒有？**
企業還沒設定預設班表。星期六、日不需要班表就會標成非工作日；其他假日與補班要由班表的假日表決定，
請管理員到「帳號管理 ／ 基本班表」建一張並設為預設。

**我明明有代理指派，行事曆上沒有？**
只有未撤銷的代理指派會顯示，而且要把月曆翻到生效期間那個月；一般成員到「個人設定 ／ 我的代理指派」確認日期，
管理員可到「權限管理中心 ／ 帳號配角色」確認。

**我請假了，但流程還是派給我簽？**
行事曆的請假只影響班表的工作時段，不會自動改派簽核者。請到「個人設定 ／ 我的代理指派」替自己設定代理人；
管理員要替別人設定，到「權限管理中心 ／ 帳號配角色」。

**我把事件從請假改成會議，班表會恢復嗎？**
會。請假與出差才會佔用班表；改成其他類型、改期或刪除時，原本那幾天的請假記錄會一併撤銷。

**班表假日選了「補假」，行事曆上顯示成假日？**
補假視同休假：那天會標成非工作日，事件標題用你填的說明。

**建立請假或出差後出現代理提示是什麼？**
系統偵測到你在那段期間有待簽核任務，或有已發行流程可能會派給你簽核。成員與企業管理員點 [設定代理人] 都會到個人設定頁的
「我的代理指派」並帶入期間與原因。
