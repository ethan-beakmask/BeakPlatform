# 企業行事曆與我的行事曆

把企業裡「跟時間有關的事」放在同一個月曆上看：公司放假與補班、誰在代理誰、
限期的兼任或代理職位、系統公告，以及你手上等著簽的單。這一版**只能看，不能新增**；
資料都來自既有功能（班表、代理授權、職位、公告、表單流程），在那些頁面改了，行事曆會跟著變。

!!! abstract "作業：看企業行事曆"
    **MENU**：行事曆 ／ 企業行事曆

    1. 進頁面預設是本月的月視圖，今天的日期有外框
    2. 按 [<] [>] 換月，按 [今天] 回到本月；按 [週] 切成一週七欄，看得到每筆的時段
    3. 點任一天的格子，跳出當日明細；有 [開啟] 連結的事件可以直接跳到來源頁
    4. 右上角 [我的行事曆] 切到個人視圖

## 兩個視圖看到的東西不一樣

| 內容 | 企業行事曆 | 我的行事曆 |
|---|---|---|
| 企業預設班表的假日、補假、補班（含非工作日底色） | 有 | 有（改用你自己的班表；沒指定就用企業預設） |
| 代理授權期間 | 只有授權人、被授權人與管理員看得到 | 同左 |
| 有期限的職位（兼任、代理、臨時） | 管理員看全部；一般成員只看自己的 | 你自己的 |
| 公告（跑馬燈公告的有效期間、緊急廣播的發布日） | 有 | 有 |
| 你待簽核的單 | 不顯示 | 顯示在送到你手上那天，[開啟] 會進表單中心 |
| 流程的等待到期（Delay 節點） | 只有管理員看得到 | 不顯示 |
| 其他成員的個人事件 | 依對方設定：公開才看得到內容，否則只看到「已排程」與時段 | 不顯示 |

## 「已排程」是什麼

其他成員把個人事件設成「僅顯示已排程」時，你只看得到他在那個時段有安排，看不到標題與內容。
設成「私人」的事件則完全不會出現，**管理員也看不到**。
這一版還沒有新增個人事件的畫面，所以目前只會看到系統從其他功能投影出來的事件。

## 日期怎麼算

所有日界都依企業設定的時區（畫面標題下方有標）。跨時區的成員看到的日期與企業一致，
不會因為瀏覽器所在地不同而差一天。

## 常見問題

**格子都是白的，沒有非工作日底色？**
企業還沒設定預設班表。請管理員到「帳號管理 ／ 基本班表」建一張並設為預設。

**我明明有代理授權，行事曆上沒有？**
只有未撤銷的授權會顯示，而且要把月曆翻到生效期間那個月；到「帳號管理 ／ 代理授權」確認日期。

**班表假日選了「補假」，行事曆上顯示成假日？**
補假視同休假：那天會標成非工作日，事件標題用你填的說明。
