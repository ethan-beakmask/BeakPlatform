# 設定代理人

請假或出差時，可以指定同事在效期內代理你的職務角色。

!!! abstract "作業：指定代理人"
    **MENU**：個人設定 ／ 我的代理指派

    1. 按 [指定代理人]
    2. 選代理人
    3. 填生效開始與生效結束
    4. 填事由
    5. 確認「將代理以下角色」清單
    6. 按 [建立]

!!! abstract "作業：從行事曆帶入"
    **MENU**：行事曆 ／ 我的行事曆

    1. 登記請假或出差
    2. 出現代理提示時按 [設定代理人]
    3. 個人設定會開啟「我的代理指派」，期間與原因已帶入
    4. 選代理人後按 [建立]

!!! abstract "作業：撤銷或放棄"
    **MENU**：個人設定 ／ 我的代理指派

    1. 「我授出的代理」按 [撤銷]，可提前結束自己授出的代理
    2. 「我代理的」按 [放棄]，可放棄別人指定給你的代理

## 注意事項

- 代理人拿到的是你的角色，不是你的本人身分。
- 代理只在效期內生效。
- 沒有可代理的角色時，畫面會提示無法指定代理人。
- 候補由管理員或部門頁登記，不在這裡設定。

## 常見問題

**代理人說看不到我的單。**
請確認代理指派效期包含該單的簽核日期，且該單屬於「將代理以下角色」清單中的角色。

**我可以同時指定兩個人嗎？**
可以，各建一次。

**可以只代理某幾張表單嗎？**
自助不行。請管理員在權限中心建立限定表單的代理。
