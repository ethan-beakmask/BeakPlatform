# 設定代理人

請假或出差時，可以指定同事在效期內代理你的職務角色。

!!! abstract "作業：指定代理人"
    **MENU**：個人設定 ／ 我的代理指派

    1. 按 [指定代理人]
    2. 進到表單中心的「代理指定申請單」
    3. 選代理人
    4. 勾選要委任的角色
    5. 填生效開始、生效結束與事由
    6. 需要時選限定表單
    7. 送出
    8. 等代理人在表單中心的待簽清單同意
    9. 對方同意後，代理指派才會出現在「我授出的代理」

!!! abstract "作業：從行事曆帶入"
    **MENU**：行事曆 ／ 我的行事曆

    1. 登記請假或出差
    2. 出現代理提示時按 [設定代理人]
    3. 系統會直接開啟「代理指定申請單」
    4. 期間與原因不會自動帶入，請在申請單上自行填寫

!!! abstract "作業：撤銷或放棄"
    **MENU**：個人設定 ／ 我的代理指派

    1. 「我授出的代理」按 [撤銷]，可提前結束自己授出的代理
    2. 「我代理的」按 [放棄]，可放棄別人指定給你的代理

## 注意事項

- 代理人拿到的是你的角色，不是你的本人身分。
- 代理只在效期內生效。
- 代理只涵蓋「以角色指定」的簽核關卡。流程若把某一關直接指名到你本人（例如依人事資料算出的核決人），代理人不會收到那一關。
- 送出後在對方同意前不會生效，可在表單中心追蹤這張單。
- 沒有可委任的角色時，申請單會顯示沒有可選項目。
- 候補由管理員或部門頁登記，不在這裡設定。

## 常見問題

**代理人說看不到我的單。**
請確認代理指派效期包含該單的簽核日期，且該關卡是以角色指定。如果流程直接指名到你本人，代理人不會收到。

**我可以同時指定兩個人嗎？**
可以，各建一次。

**可以只代理某幾張表單嗎？**
可以，申請單上的「限定表單」留空表示不限；有選表單時，只限代理人簽那些表單。

**送出後對方一直沒處理怎麼辦？**
到表單中心「我的申請」看進度，或請對方到待簽清單處理。
